## 📄 重要论文

- **CERA-MoA：路由机制与持续学习 Agent 协同演化**：针对现有 Mixture-of-Agents 将查询路由与 Agent 微调割裂的问题，提出迭代式共同演化框架，让路由策略随 Agent 能力变化而自适应。
  - 重要性：★★★★★ / 5
  - 核心价值：多 Agent 系统的路由与微调可联合优化，降低手工调度成本
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.18779)

- **Fathom：面向卸载 KV Cache 的按查询读取深度稀疏解码**：针对百万 token 级 agentic 会话，将 4-bit K cache 按 channel-major 存为 bit planes，让每个 query 自行决定读取多少位，从而缓解解码带宽瓶颈。
  - 重要性：★★★★★ / 5
  - 核心价值：长上下文 Agent 服务的显存与带宽瓶颈有了新解法
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.17652)

- **Edge0：从 SSD 服务 35B MoE，用预路由预测隐藏读取延迟**：指出朴素 SSD offload 无效的原因是第 N+1 层专家必须在第 N 层输出前选定，提出 prerouter 逐层预测专家选择以提前发起读取。
  - 重要性：★★★★★ / 5
  - 核心价值：消费级硬件跑大 MoE 的可行性显著提升
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.18063)

- **In-Context Robot Learning with VLM Agents**：探索用商用 VLM（如 GPT-6 Astra）的通用 agentic 能力实现机器人的上下文学习，让机器人在部署时从上下文中适应新任务。
  - 重要性：★★★★★ / 5
  - 核心价值：具身智能的泛化路径可能从微调转向上下文学习
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.19138)

- **PPO 中的 Value Flattening：理解并缓解 critic 失效模式**：发现 PPO critic 存在系统性失效——中间状态的真实价值变化剧烈而 critic 预测近乎平坦，并在 FrozenLake 环境中复现。

- **Agora：用 Git 作为集体 AutoResearch 的共享记忆**：把研究过程记录为存储在 Git 中的 append-only DAG，每个 claim 都是一次可 checkout 重跑的 commit，解决多 Agent 重复搜索问题。
