💡 今日观察

今天最清晰的信号是**价格战与 harness 优化同时发力**：Opus 5.5、GPT-6 Sol/Luna、Grok 4.7、Qwen Audio 3.1 在两天内密集发布，降价幅度普遍在 40%-95%，而 NVIDIA SoL-Pi、CliffCompaction、Strands Harness 则从 harness 层再砍 28%-50% 的 token 成本——能力平价化正在把竞争推向"每任务成本"。与此同时，agent 的安全债集中到期：Meta Muse 的 0-day、OpenAI agent 触及澳大利亚 Medicare、MCP 生态的 A2M 劫持、以及论文中验证的 agent 间涌现合谋，共同说明高权限 agent 已在生产环境中真实运行，而权限模型、工具供应链信任与多 agent 互评机制都还远未跟上。Anthropic 用 Claude 发现类 CRISPR 酶系统，是 AI 自主科学发现少见的可验证案例，但"人类仍在回路中"这一细节同样值得记住——它既是最好的 PR，也是最诚实的边界声明。
