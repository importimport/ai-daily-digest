📄 Papers

SiliconBench: Speed, Memory, and Fidelity for LLM Serving on Unified-Memory Desktops
Evaluates nine Apple Silicon serving engines across three lenses, covering chat and agent serving on Qwen3, Qwen3.5, and Gemma 4, with NVIDIA as a quality reference.
APort Vault: Benchmarking AI Agent Payment Authorization with the Open Agent Passport
Replays 4,371 human-written attacks across 14 models from 8 labs, five policy configurations, and 225,964 evaluations, testing a deterministic pre-action check.
CADWorld: Computer-Use Benchmark for Long-Horizon Computer-Aided Design
Targets professional engineering workflows like mechanical CAD that produce persistent structured artifacts, filling a gap in existing benchmarks.
GAVEL: Graph World Models for Verified and Efficient Long-Horizon LLM Task Planning
Uses an explicit graph of object relations, action pre-conditions and effects, and probabilistic beliefs over unobserved objects to handle embodiment constraints and partial observability.
MintAct: A Unified Visual Agent for Digital Environments
Unifies UI grounding, multi-step navigation across mobile, desktop, and web, and visual tool use at 2B/4B/8B scales, matching per-domain specialists.
CodeMidas: Scaling Agentic Coding RL Environments from Code Itself
Turns implemented functionality in existing codebases into executable RL environments using source code as evidence, breaking the reliance on issues and commits.
When AI Reviews Train AI Reviewers: Scientific-Judgment Collapse and Mitigation
Starting from Llama 3.1 8B, fine-tunes a reviewer on 2018–2023 ICLR reviews and then trains further, studying degradation from recursive AI peer review.
MoME: Mixture-of-Memory Embeddings for Context-Aware Sparse Lookup
Shows existing memory-embedding methods retrieve via a deterministic function of surface form, collapsing different contextual senses (python the language vs. the animal) into one fixed entry.
EvoOntology: A Self-Evolving Ontology Layer for Data Agents
Addresses the agent-data gap in heterogeneous data with a self-evolving ontology layer, replacing direct raw-data exploration or manually injected semantic layers.
Gricea: An Open Science Platform for Conversational AI Research
Represents studies as configurable, deployable research artifacts that can be run, inspected, shared, and reused, fixing fragmented reporting of systems and study configurations.
Calibrating Teacher–Student Discrepancy for On-Policy Distillation
Argues the observed teacher-student discrepancy doesn't purely reflect capability gaps but also contains the teacher's own deviations, which standard OPD learns indiscriminately.
IntBMoE: Integrating Block-Level Conditioning into Expert Composition for Full-Participation MoE
Notes existing designs can't set participation, execution, and materialization independently; sparse routing cuts compute and memory but shrinks per-token expert participation.
