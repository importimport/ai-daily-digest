早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 12 日，星期四。今天信息量很大，一句话概括看点：Google 一口气甩出四张牌，从决策模型到基因模型再到形式化验证，而 Anthropic 那边则在用 AI 拆 NVIDIA 的护城河，同时硬件侧传来不少让人皱眉的消息。
先来说 Google。今天最值得关注的是 Gemini Decision 1 和配套的 Decisions API。简单说，它把"分类判定"这件事从生成式推理里剥了出来，一次前向就能对最多一千个是或否、多选、打分问题输出校准概率，文本图像音频视频 PDF 全支持，延迟只有一百五十到两百五十毫秒，定价是每百万输入 token 零点一美元，输出免费。这意味着线上大量"拿生成模型做分类"的调用，成本可以降一个量级。同一时间，Google DeepMind 还发布了 AlphaGenome 2，一个条件化 DNA 序列模型，能按细胞类型预测调控活性和变异效应，已经通过 API 向非商业研究开放。另外，AlphaProof Code 用四周时间完成了 Signal 加密核心的形式化验证，写出超过六百万行 Lean 证明代码，只有大约百分之一需要人工复核，传统流程要数年。还有 Gemini 4 Carbon 全面开放，定价每百万 token 两美元和十美元，但注意，十二月一号起翻倍，想低成本试用的要抓紧这个窗口期。
再看 Anthropic。他们推出了自己的 AI 办公套件，Claude 可以自己参会、生成表格和 PPT，直接杀进微软和 Google 的地盘，同时启动了 IPO 路演。更劲爆的是，Anthropic 说自家的 Mythos 模型几乎无人干预，三天就把 Claude 移植到了 AMD GPU 上，原来要几个月，现在跑在 AWS Trainium、Google TPU、NVIDIA 和 AMD 四类芯片上，CUDA 的护城河正在被实质性削弱。
硬件和资本侧消息比较沉重。NVIDIA 董事会据报准备罢免 Jensen Huang，股价已经下跌，全球最重要 AI 芯片公司的治理风险需要重新评估。英国 Fractile 完成七点二亿美元融资，成为专用 AI 芯片赛道资金最充裕的玩家之一。另外有调查称，美国数据经纪商向中国实验室出售了约五亿美元的强化学习训练环境，出口管制几乎覆盖不到。Meta 的基础设施负责人 Santosh Janardhan 也宣布离职。
产品和生态方面，United Airlines 禁止第三方 AI agent 代客订票，此前 eBay 也封了 Meta Muse 等 agent 浏览平台，agent 电商正在遭遇平台侧的硬封锁。OpenAI 季度营收达到一百亿美元，环比增五成，但调整后经营亏损扩大到一百零九亿美元，而 Anthropic 以一百七十亿美元营收跑得更高效。
论文和开源今天也很热闹。Deletion Tuning 提出只把不到百分之零点零五的权重置零，就能媲美全量微调，后训练从"改权重"转向"删权重"。MACaQ 让四比特权激活量化落地更简单。安全侧，微软研究院用不到十个休眠神经元就给 AI agent 植入了后门，来源不明的权重风险陡增。开源方面，Meta 的 astryx 设计系统、addyosmani 的 agent-skills、shadcn 的 improve 模型分层编排、OpenAI 官方的 codex-security，还有 AWS 的本地模拟器 aws-emulator，都值得一看。语音这块，Fish Audio 的 Live 3 支持全双工、最快一百八十六毫秒响应，打断处理这个短板正在被补齐。
最后是今日观察。今天最强的信号，是 AI 正在用 AI 压缩自己的成本结构：AlphaProof 四周做完数年的验证，Anthropic 三天完成 CUDA 到 AMD 的移植，Deletion Tuning 用极少的权重删除替代全量微调，三件事指向同一个方向，模型能力正在反过来削减训练、验证和硬件绑定的边际成本。而 Gemini Decision 1 把判定变成廉价单次调用，是今年最容易被低估的 API 形态变化，建议尽快把线上的分类、审核、打分链路做一次成本重算。风险侧同样密集，神经元级后门、平台封堵 agent、NVIDIA 治理危机叠加消费级大显存路线收窄，依赖单一算力供应商的团队，是时候准备备选方案了。好，今天就聊到这儿，我们明天见。
