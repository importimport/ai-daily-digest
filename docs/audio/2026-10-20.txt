早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 20 号，星期二。今天的关键词有两个，一个是 Agent 安全开始真刀真枪地出事故，另一个是算力层围绕 Nvidia 的合纵连横明显加速。咱们花几分钟，把重点捋一遍。
先看行业这边。NVIDIA 今天动作最大，直接把完整的 GPU 编排平台 Run:ai 用 Apache 2.0 协议开源了，里面包含 KAI Scheduler、CUDA 13.4 的 GPU 分片、配额管理，还有本地 Kind 开发环境。换句话说，在 Kubernetes 上做 GPU 调度和多租户分片，现在可以直接用生产级方案了。同一天，NVIDIA 还发布了面向企业和 PC 的开源 Agent 模型，私有化部署和端侧 Agent 又多了一套官方权重和工具链。
不过挑战者也都在动。Amazon 推出了 TorchNeuron 开发工具，摆明了要撬动 Nvidia 对 PyTorch 生态的掌控，让应用更容易跑到 Trainium 这类替代芯片上。Tenstorrent 则完成了 15 亿美元融资，估值 62 亿，坚持保持独立。算力层的去 Nvidia 化，和编排标准化，正在同步推进。
但算力供给端本身也在洗牌。业内预计，数百家 AI 云厂商最后可能只剩七到十家，CoreWeave 市值蒸发四分之一，微软还撤出了跟 Nscale 的 2.3 万张 Nvidia 芯片订单。另一边，Nscale 和 Anthropic 据报正在谈第二份 450 亿美元的算力大单，前沿实验室的算力焦虑一点没减。
安全这块今天特别值得说。开源编码 Agent OpenCode 被黑客攻击了 48 小时，部分用户 API Key 泄露被盗刷，更尴尬的是，它求助的 AI 工具居然拒绝查看恶意代码。Microsoft 也出来警告，说企业要密切监控员工使用的第三方 Agent，直言前沿模型不可信。法律层面，德国两家法院接连裁定，Google 要为 AI Overviews 生成的内容负责，AI 答案被视为公司自有内容，搜索产品的合规风险陡增。
模型和论文方面，Kling AI 发布 4.0，支持最长 30 秒片段、10 张关键帧输入，还加了立体声和多语言口型同步。MiniMax M3.1 Flash 也来了，428B 参数的 MoE，激活约 23B，1M 上下文，API 定价压到每百万 token 零点一五和零点六美元，权重 10 月 23 号开放。Google 开源了 Harness2 递归 Agent 框架，不改权重，只重写 Agent 的 harness，单次精炼就让 GLM-5 在 WorkBuddy-Bench 上提升 11.5 分。Mistral 则发布 Timestral 时序基础模型，209M 版本在零样本模型里领跑，还能在 CPU 上跑。
开源项目里，求职框架 ai-job-search 一天涨了三千八百多星，管理 Agent 舰队的 orca 和开源编码 Agent opencode 也都很热。另外，VAST 开源了实时世界模型 EdenLive，单张消费级显卡就能跑 720P、超 24 帧的交互式生成。
最后说一条圈内热议：有用户基于 1629 条公开结果发现，AI 实验室自报的 benchmark 分数，平均比独立测试高 6.4%。所以选型的时候，还是多看看独立评测。
今日观察。今天最清晰的信号，是 Agent 安全从论文走进了事故现场：OpenCode 被黑、AI 拒看恶意代码、Microsoft 直言模型不可信、德国法院让 Google 担责，权限边界和可审计性正在成为产品的一等公民。与此同时，算力层的去 Nvidia 化和编排标准化在加速，而 Harness2 证明，不改权重、只改 harness 也能涨 11.5 分，工程红利正在超过参数红利。最值得警惕的是 Anthropic 初级岗位占比从 27% 掉到 9% 这组数据，当 Agent 的工作时长已经是人类的 6 倍，人才培养的断层，可能比岗位消失来得更晚，也更痛。好，今天就聊到这儿，我们明天见。
