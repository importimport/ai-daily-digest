早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 9 月 12 日，星期六。今天的关键词只有一个，agent 基础设施化。OpenAI 一口气放出了 Agents API 和全双工语音接口，把 agent 从演示推向了可托管服务；而 Anthropic 的滥用报告则把模型安全的老问题摆上了台面。咱们分几个板块来聊。
先看 OpenAI。他们发布了 Agents API 的公测版，开发者可以构建在云端自主运行数小时、执行代码并交接子任务的 agent，除了 token 之外没有额外费用，Cloudflare、Vercel 和 Oracle 提供沙箱环境。这是 Codex 和 ChatGPT 背后的 agent 基础设施第一次对外开放。同时，GPT-Live-1 全双工语音 API 也来了，可以同时听和说，交互性测试得分从上一代的百分之四十五点四提升到百分之八十点一，定价是每分钟零点零五美元。实时语音 agent 的延迟和打断问题，终于有了官方解法。
但 OpenAI 这边也不全是好消息。二十五位顶尖数学家联名发公开信，指控 AI 实验室威胁他们的智力劳动成果，此前已经有研究者质疑 OpenAI 数学训练数据来源不透明。这场冲突还在升级。另一边，OpenAI 还在就行业集体减速的合法性咨询国会，担心反垄断法会阻碍他们眼中日益紧迫的协同减速行动。前沿实验室开始为监管协调预铺法律路径了。
再看 Anthropic。他们发布了一份 Claude 滥用威胁情报报告，记录了八个月内八起滥用事件，涉及导弹软件、自杀式无人机蜂群和全国性监控系统。报告还指出，阿里 Qwen、DeepSeek 和 Moonshot 被指大规模转接请求或抽取训练数据，Qwen 一家就超过一点五一亿次交互。模型滥用和蒸馏攻击第一次被量化披露。与此同时，Anthropic 的研究员 Jacob Coxon 离职并在 X 上发出末日警告，说公司正径直冲向自我改进的超智能，拿我们的生命赌博，而公司的 alignment 负责人竟然联署了这条推文而不是澄清。这个时间点很微妙，因为 Anthropic 正在筹备 IPO。
国内方面，Moonshot AI 瞄准二十亿美元年收入，K3 模型在 OpenRouter 上日均生成约三千亿 token，尽管近月使用量略有下滑。银河通用成立三十四个月融资七十亿，背后至少有十七家国资机构，具身智能赛道的资本集中度值得警惕。字节、阿里、腾讯同时收兵 AI 办公，智能体要成为企业数字员工还长路漫漫，入口争夺战才刚刚开始。
Meta 这边因为 AI 训练数据和人脸识别被集体诉讼，诉状指控 Meta 非法采集 Facebook 和 Instagram 的照片，用于训练图像生成模型以及未发布的 NameTag 人脸识别功能。社交平台照片用于训练的合规风险正在集中爆发。
技术侧也有不少看点。OpenAI 披露了支撑十亿 ChatGPT 用户的存储架构 Habitat，从 Python 库演进为全球分布式存储平台，承载每秒两千两百万次请求。Google DeepMind 发布了 AlphaGenome Atlas，绘制了人类基因组九十亿个单字母 DNA 变异的分子效应预测图谱。Y Combinator 的 Garry Tan 则呼吁美国开源权重实验室也做蒸馏，主张小型美国实验室对美国前沿模型采用同类训练技术，提供非中国的开源权重选择。开源权重的地缘政治化，让蒸馏的正当性成了新战场。
论文方面，今天有几篇值得关注。NCP-ArchPreview 尝试在标准下一 token 预测之外增加跨多 token 的离散概念预测目标，可能是预训练目标的下一次范式试探。T1 给出了面向长时程任务的终端 agent 强化学习完整配方，一百二十二 B 的 MoE 模型在云沙箱中操作真实 shell，单任务最多三百多轮工具调用。还有 IMO 金牌开源配方，基于 Nemotron 训练奥数证明，纯自然语言运行，不需要形式化证明器或联网。Negative Self-Distillation 则指出了自蒸馏范式的一个已知坑，学生会模仿人为自信的推理轨迹、抑制探索，并提出了修正方案。
开源项目里，今天有两个增长很猛。obra/superpowers 是一套 agentic skills 框架与软件开发方法论，单日涨了七百多星。ayghri/i-have-adhd 更夸张，单日涨了三千四百多星，它就是一个让 coding agent 不再把答案埋在长篇输出里的 skill，解决的是 agent 输出冗长的普遍痛点。另外 vastsa/PI-Desktop 是本地优先的 AI coding agent 桌面端完整开源实现，nashsu/llmwiki 则尝试用增量维护的持久 wiki 取代传统 RAG。
最后聊一条社区热议。Simon Willison 回应了对 AI 感到难过这个话题，他说许多人都经历过这种存在主义危机并走了出来。当 coding agent 一小时干完你一周的活时，第一反应是沮丧，但一旦接受把精确规格翻译成好代码这件事被自动化，就该重新定位自己的价值。
今日观察。今天的信号高度集中在 agent 基础设施化。OpenAI 把 Codex 和 ChatGPT 背后的编排、长会话、工具调用能力直接商品化，agent 从 demo 走向可托管服务。与此同时，Anthropic 的威胁情报报告把一个此前只在传闻中的事实摆上台面，模型既被用于导弹与无人机，也被同行大规模转接抽取训练数据，安全与竞争已经纠缠不清。对 builder 来说，最实际的动作是，今天就去评估 Agents API 的托管边界，同时认真读一遍 Anthropic 的滥用报告，因为你的 agent 可能正处在同样的风险面上。好，以上就是今天的全部内容，我们明天见。
