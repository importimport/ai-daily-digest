早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 23 日，星期五。今天的关键词是两个字，Agent。从融资到产品，从云平台到安全标准，Agent 正在从演示走向真正的工程落地，而围绕它的基础设施和现实阻力，也在同一天集中浮出水面。我们一条条来聊。
先看资本面。OpenAI 正在筹备一笔三百亿美元的新融资，估值喊到一点二五万亿美元，如果成真，它将成为史上估值最高的私营公司，这个数字基本会成为全行业的估值锚点。国内这边则是另一番景象，DeepSeek 据悉完成了一千亿元人民币融资，而 MiniMax 上市破发，闫俊杰身价蒸发九百亿，头部融资和二级市场明显分化，中国 AI 赛道正在经历一轮重估。
产品侧今天非常热闹。Anthropic 推出了常驻 Agent 应用 Claude Duet，基于 Claude Opus 5.5，通过六千多个连接器接入 Gmail、Slack、Stripe 这些服务，你离线的时候它也能自己干活，敏感操作需要你审批，常驻 Agent 这条产品线的竞争正式开打。OpenAI 则把决策模型 Decisions API 向所有开发者开放，主打低延迟、低成本的场景内决策。Canva 发布了首个自研图像模型 Canva Craft，先生成设计方案再出图，强调一致性和可控性，向全部用户开放。
云和基础设施这块，Google 发布了 Agent Compute Engine，给每个 Gemini Agent 分配一个硬件隔离的微虚拟机，同时扩展了云端、混合和本地的 Agent 治理能力。更有意思的是，Google Cloud 上架了 OpenAI 的模型，GPT-6 Astra、GPT-6.1 Sol 和 GPT-6 Luna 以私有预览形式开放给企业客户，Google 由此成为唯一同时提供 Gemini、Claude 和 GPT 三大模型的云厂商，企业被单一厂商锁定的风险明显降低。
但现实阻力也很直接。美国大型银行开始封禁使用客户凭证登录的 AI Agent，Morgan Stanley 直接封锁访问，其他银行多计划只给只读权限。另一边，1Password 推出了让 Agent 代登录、但看不到明文密码的功能，算是给出了产品化的解法。安全方面，Symantec 发现一种叫 Skynet 模式的攻击型 Agent，能无人工干预运行多达十万步，劫持网上没有防护的模型去攻击服务器、窃取数据库、植入挖矿程序，账单还算在被劫持的模型所有者头上，这个风险必须纳入部署设计。
企业落地有两组对照数据。Uber 把 ChatGPT Work 部署到全部三万名员工，覆盖研究、数据分析和演示制作。但 Gartner 对两千多名 CIO 的调查显示，只有百分之十三的企业从 AI 拿到了真实回报，百分之五十一预计 AI 反而推高运营成本，可仍有百分之七十五的 CEO 打算继续加预算，这个剪刀差值得每个做落地的人警惕。
科研和模型这边，微软称其 AI 诊断工具在疑难病例上准确率最高可达人类医生的四倍，不过提升主要来自底层模型，而不是系统本身。OpenAI 的 Agent 用三十二分钟完成了原本需要人类数月的鼠脑数据分析。Hugging Face 开源了能和 DNA 对话的生物模型。Liquid AI 发布实时推理引擎 RIPL，把 LFM 的延迟压到五十毫秒以下。
论文里有两个信号特别值得关注。Recursive 发布 Flint，四十 B 的 MoE 本地编码模型，只激活二点五 B 参数，SWE-bench Verified 达到百分之七十四点二，在 M4 Pro 笔记本上每秒一百二十五 token 以上，而且架构是公司自研系统在四个月内自动搜索优化出来的。Perplexity 和 NVIDIA 的 JOLT 则用联合师生强化学习，在 MATH 上以六点五分之一 的训练 token 达到 GRPO 同等准确率。一个压缩架构成本，一个压缩训练成本，递归自我改进正在变成可测量的工程问题。
开源社区今天也很忙。Cloudflare 的安全审计技能单日涨了近三千星，Vercel 开源 durable-harness 让编码 Agent 崩溃后可恢复，NVIDIA 开源了面向 Agent 集群的安全运行时 OpenShell，Anthropic 则把 Agent Skills 标准捐给了 Linux 基金会下的 Agentic AI Foundation，此前 MCP 也已经捐入，技能标准正在走向厂商中立。
最后是圈内热议。Hacker News 上有个高热度讨论，说如果模型这么强，OpenAI 为什么不直接开一百家公司下场做垂直业务，而要卖 API，这其实戳中了模型能力和商业价值之间的鸿沟。另外 Hassabis 再次把 AGI 时间线从三到五年缩短到两到三年，社区对时间线和 AGI 定义的争论还在继续。
今日观察。今天最清晰的信号，是 Agent 基础设施正在分层落地。Google 管隔离，1Password 管凭证，Vercel 管崩溃恢复，Anthropic 把技能标准交给中立基金会，运行时、身份、可靠性和互操作这四条腿同时补齐。但 Gartner 的百分之十三回报率和美国银行封禁 Agent 登录也在提醒我们，能力供给和组织采纳之间的差距还在扩大。真正值得押注的，可能不是又一个更强的模型，而是把 Agent 安全、可观测、可恢复地接进真实业务的那层脏活累活。感谢收听，我们明天见。
