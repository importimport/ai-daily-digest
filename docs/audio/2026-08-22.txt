各位听众朋友，早上好！今天是八月二十二号，星期六。欢迎收听今天的AI行业播报。今天这期节目信息量非常大，从芯片收购到模型发布，再到开源项目井喷，咱们慢慢聊。
先说最重磅的消息。Nvidia 砸下六十亿美元，收购了 Poolside 的 Model Factory 软件平台，连带一百零九名员工一起收入囊中。这步棋很明确，Nvidia 不满足于只卖显卡了，它要把手伸进模型开发生态，从硬件厂商向软件平台延伸。
另一边，OpenAI 这季度财报很亮眼，营收增长了百分之三十五，企业业务更是涨了超过五成，在商业API支出上首次超过了 Anthropic。这背后是 GPT-5.6 Sol 这个新模型的功劳，看来模型竞争力直接决定了市场份额，这话一点不假。
Anthropic 也没闲着，把自家最强的 Claude Mythos 5 用到了网络安全防御上，推出了漏洞扫描和修复建议服务。企业客户不用直接访问模型，就能获得顶级的扫描能力，这招挺聪明的。
接下来是自动驾驶领域的大新闻。Waymo 开始自研芯片了，专门给他们的 Robotaxi 用，目的是减少对 Nvidia 的依赖。头部公司垂直整合芯片，供应链格局怕是要变天。
Slack 也来凑热闹，推出了 Slack Code，把 Claude Code、Devin、GitHub Copilot 这些AI编程工具直接嵌进聊天频道里。AI编程从个人终端走向团队协作，开发工作流正在被重塑。
Meta 发布了 Mac 版的 AI 应用，支持屏幕内容理解和全应用听写，这是要跟 OpenAI 和 Anthropic 在桌面端正面刚了。另外有消息说，Meta 每年向微软的AI服务投入数亿美元，成了微软最大的AI客户之一，巨头之间的采购关系真是越来越复杂。
再来看几个有意思的技术进展。Nvidia 的研究人员发现，用简单的线性数学就能替代昂贵的模型间任务交接，他们搞了个跨模型 KV 缓存迁移技术，能大幅降低多模型工作流的计算成本和延迟。这对多智能体协作来说是个重大突破。
DeepSeek 发布了多模态实验模型 V4-Flash-Vision-Exp，在自家的智能体基准上接近甚至超过了 Opus 4.8，开源模型正在逼近闭源前沿。
OpenAI 的 GPT-Image-2 现在能直接生成透明背景的图像了，省去了后期抠图的麻烦，设计师们有福了。
还有个神秘模型叫 Ox Alpha，突然出现在 OpenRouter 上，性能据说超过了 Fable 5，全网都在猜它背后是智谱还是小米。这要是真的，可能预示着新的开源模型要发布了。
论文方面，Nvidia 的 AVO 在 ARC-AGI-3 上拿了满分，完成了全部关卡，而且不需要任何指令、规则或目标说明，通用智能体的自主推理能力又上了一个台阶。另外 FlashPrefill V2 把长上下文推理的预填充阶段加速到了生产级别，直接降低服务成本。
开源项目今天也是大爆发。有个叫 skills 的项目，来自知名工程师 Matt Pocock，一天就涨了三千多星。还有 MoneyPrinterTurbo，一键生成高清短视频，内容创作者可以关注一下。Apache 孵化的 maka 项目，做的是本地优先的AI智能体工作区，所有交互都有日志记录，可审计性很强。字节跳动开源了 OpenViking，是个自进化上下文数据库，统一管理智能体的记忆和知识。xAI 也开源了 grok-build，是个编码智能体框架，支持全屏和鼠标交互。
社区热议方面，有个话题挺有意思，有人在争论"别再搞终端界面了"，说现在AI编程已经把GUI开发成本降得很低，就算是最小的个人工具也应该做真正的原生界面。另一个热点是 Qwen3.8-27B 这个本地小模型，在智能体编码任务里表现惊人，有人让它连续跑了二十个小时，速度稳定在每秒六十多个token，效果比一些商业模型还好。这可能会改变"必须用闭源大模型"的认知。
今日观察。今天最核心的信号是智能体基础设施的全面爆发。从 Nvidia 的 KV 缓存迁移技术，到 GitHub 上大量智能体技能、记忆、工作区项目，行业正在从模型竞赛转向智能体工程竞赛。第二个趋势是本地小模型在智能体场景中的崛起，Qwen 和 DeepSeek 的表现说明，开源加本地部署的智能体工作流可能成为企业的新选择。最后，Anthropic 和 OpenAI 都在调整企业数据隐私政策，零数据保留、数据保留放宽，这说明企业级信任正在成为模型厂商竞争的下一个主战场。
