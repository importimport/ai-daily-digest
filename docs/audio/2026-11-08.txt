早上好，今天是 2026 年 11 月 8 日，欢迎收听今天的 AI 日报。今天的关键词是“收敛”和“加速”同时发生：一边是资本和收入预期在降温，另一边是模型能力和安全风险在提速。我们一条条来聊。
先看资本面。OpenAI 又融了 110 亿美元，估值到了 1.25 万亿美元，这是新一轮融资的首笔款项，整轮规模可能达到 200 亿美元，而且已经开始向富裕个人投资者募资。另一边，Anthropic 顶着科技股抛售，坚持在感恩节前推进 IPO，但接受了更低的估值，目标区间是 1.25 到 1.75 万亿美元，远低于原本期望的 2 万亿，拟募资 800 到 1000 亿美元。这两件事放在一起看，头部模型公司的定价正在成为整个行业的估值锚点。更有意思的是 Ramp 的数据：AI 使用量还在涨，但企业支出走平了，降价和成本控制把账单压住了。也就是说，AI 收入超高速增长的假设，正在被真实账单挑战。
技术侧的消息更刺激。METR 发了一份历时 11 周的调查报告，说 Anthropic 正在用 AI 加速自己的 AI 研发，模型改进速度大约是去年同期的两倍。递归自我改进这件事，正在从假设变成可观测的趋势，安全研究者对此相当警觉。与此同时，OpenAI 发布了 GPT-6 Cyber 安全模型，专门用来发现可利用漏洞并给出修复方案，训练时约束它只在授权范围内行动。安全攻防正在成为前沿模型的新战场。
说到安全，有两件事得提醒大家。第一，Claude Code 的“Don't Ask Again”功能导致密码泄露到了一千一百二十二个公开的 GitHub 文件里，编码代理把密钥写进了可公开访问的配置文件，这说明 Agent 的权限持久化设计必须默认最小化和脱敏。第二，Vals AI 的基准显示，开源模型在网络攻击能力上正在逼近闭源，DeepSeek V4.1 Flash 用十分之一的成本达到了 72.8% 的攻击目标，而闭源这边是 80.8%。开源权重不可撤回，防守方的窗口在真实收窄。
产品和生态方面。Perplexity 推出了常驻 Agent“Teammates”，每个 Agent 跑在独立虚拟机上，持续推进长期项目，需要每月 200 美元的 Max 套餐。Meta 给 Muse Agent 推出了“Spaces”，用户可以在里面搭购物中心、学习面板这类应用化的自定义体验，Agent 正在从对话走向可组装的个人应用容器。Google 发布了 Gemini Omni 1.2 Flash，原生支持 15 秒视频生成和多轮对话式编辑，720p 视频降价 30%，到每秒 0.07 美元，这对批量内容生产管线是实打实的利好。另外，Microsoft Research 的 AI Frontiers 团队宣告结束，负责人 John Langford 在博客里披露了这个消息，大厂基础研究组织在收缩，方向更偏产品化。
政策和基建这边，美国中期选举之后，41 项数据中心相关公投里有 40 项通过了限制性措施，民主党大胜，AI 数据中心的扩张面临更强的政治阻力，算力基建的政策风险明显上升，选址和电力成本都会承压。
再看几篇值得留意的论文。有一篇挑战了“工具输出必须以文本进入上下文”这个假设，用隐空间压缩工具观测，提升多步 Agent 的上下文效率。还有一篇用稀疏自编码器分析 MoE 专家，发现专家有细粒度、人类可解释的专精。另一篇比较有意思：150 个同数据、同安全训练、只是预训练随机种子不同的模型，越狱脆弱性差异显著，说明越狱评测的结论不能跨 checkpoint 外推。线性注意力那边也有新设计原则，指出状态更新对“擦除”的敏感度远低于“写入”，据此重新分配门控。还有 Open-HumanScale，首个把第一视角人类视频扩展到 5 万小时的完全开放配方，对具身基础模型是重要的数据基建。
开源项目快速过几个。Cloudflare 出了个 security-audit-skill，把多阶段安全审计做成可复用的 Agent 技能，单日涨了两千多 star。Vercel 出了面向 Agent 的浏览器自动化命令行工具。Thinking Machines 发布 Inkling 2 Small，594B 的 MoE、17B 激活，智能指数 31 分，Apache 2.0 权重在计划中。Buoyant 开源了 Kinference，Kubernetes 加 vLLM 的推理控制平面，官方基准里首 token 延迟中位数降低了 95%。Zyphra 则给 AMD MI355X 做了 FP8 的 FlashAttention 内核，比 AMD 自家的 AITER 快 1.16 到 1.76 倍。
最后是圈内热议。“Agent Skills”仓库集体霸榜 GitHub Trending，anthropics、google 等几个 skills 仓库同日上榜，社区正在围绕“技能目录”这个形态快速形成事实标准。但与此同时，也有人警告 AGENTS.MD 可能成为新型攻击面。Agent 能力的分发，正在从 prompt 转向可安装的技能包。
今日观察。今天最清晰的信号是，资本与能力同时进入收敛期：OpenAI 转向个人投资者，Anthropic 下调 IPO 估值，Ramp 数据显示企业支出走平，三者指向同一个事实，AI 收入曲线不能再靠叙事支撑。但技术侧恰恰相反，METR 的报告让递归自我改进有了实证，开源模型在网络攻击能力上只落后闭源 8 个百分点，防守窗口在真实收窄。而中间层最值得关注的，是 Agent Skills 生态的爆发，它正在把 Agent 能力从一次性 prompt 变成可分发、可审计、也可能被投毒的软件资产。Cloudflare 的审计技能和 AGENTS.MD 的安全警告，其实是同一枚硬币的两面。好，今天就聊到这儿，我们明天见。
