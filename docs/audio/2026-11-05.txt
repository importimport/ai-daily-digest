早上好，今天是 2026 年 11 月 5 日，欢迎收听 AI 行业每日播报。今天最值得关注的，是 AI 竞争的重心正在从模型能力本身，转向围绕模型的基础设施和信任层；另外，物理世界的约束也开始反噬算力扩张。我们逐一来听。
先看 OpenAI，今天动作非常密集。它发布了 Images 2.6，ChatGPT 现在原生支持生成 GIF 动图，可以从文本或图片生成，还能调节播放速度、逐帧编辑，同步登陆 Codex 和 API，图像编辑的精度和一致性都有提升。同一天，OpenAI 还收购了 Pierre Computer Company，为 AI 编程 agent 改造 Git，配合自研的 Git 后端 Pando，构建面向 agent 协作的开发基础设施。更硬核的一条是，OpenAI 用自动化流水线在 Linux 内核里发现并修复了 948 个本地提权漏洞，从发现、验证到生成补丁全流程自主完成，AI 安全审计正在从辅助走向端到端自动化。
Meta 这边也没闲着，收购了 AI 编程初创 Conductor。这家公司允许工程师同时部署多个 agent 并行处理项目的不同部分，Meta 借此补强 agentic coding 能力，多 agent 并行编程正式进入大厂产品线。
不过，agent 的商业化现实还得冷静看。Uber 披露，上季度只有 4 单是由第三方 AI agent 完成叫车，Uber Eats 的 agent 订单大约 500 单，说明 agent 替代 App 的叙事还需要现实校准。Google 那边也有烦恼，搜索查询量创下五年最快增长，但收入增速却降到了 12%，AI Overviews 拉动了使用量，却没带来对等的广告收入，AI 搜索对广告模式的侵蚀开始显性化。
再看硬件和政治层面。美国中期选举中，多个选区通过了限制数据中心的动议，76% 的受访选民对数据中心持负面态度，算力扩张正面临地方政治阻力。供应链上，AI 需求引发 PCB 严重短缺，交期拉长到 30 个月，材料成本涨了 12 倍，PC 厂商订单都排到 2030 年了。Qualcomm 则发布 Cloud AI 100 Ultra，150 瓦、128GB 显存、548GB/s 带宽，在手机业务下滑约 20% 后全面押注数据中心加速卡。
研究方面有几条很值得琢磨。Anthropic 发布 FlashProve，用 zkSNARK 证明回答确实来自承诺的权重，单张 H100 上就能以每秒 110 个 token 的速度为 Llama 4 Maverick 生成 19MB 的证明，而且不暴露模型权重，给模型溯源和合规审计提供了可验证的密码学方案。MIT 的研究更有意思，GPT-6 Astra 可以直接读写其他模型的权重，只改动 Qwen 模型 0.016% 的权重，数学准确率就从 7.9% 提升到 48.1%，无需传统训练。Stanford 的研究则泼了盆冷水：44% 的 LLM 研究结论已经过期，平均有效期只有 15.7 个月。
还有两条关于上下文的结论值得 builder 注意。一条说频繁压缩上下文几乎不损精度，长上下文成本可以大幅压缩；另一条说长上下文失效的根源是干扰而不是长度，中性填充下 32K 以内准确率能维持在 0.97 到 1.00，但同格式的干扰句能把它压到 0.16 到 0.33。也就是说，RAG 和记忆系统应该优先去重、去干扰。
开源项目方面，Ricursive 发布 Ripple-65B Preview，Apache 2.0 开源权重，Terminal-Bench 2.1 得分 80.5，成绩超过体积达它 15 倍的美国开源模型。腾讯微信视觉团队开源 WeVisOne-VL，2B 和 4B 两个版本，单模型统一检测、OCR、计数、分割等任务。另外 claude-mem 这个项目为所有 agent 提供跨会话持久记忆，兼容 Claude Code、Codex、Gemini、Copilot 等工具。还有个极客项目挺吸睛，kimi-k3-in-c 让 2.78 万亿参数的 Kimi K3 在单 CPU、8.24GB 内存上跑推理，纯 C99，不用 GPU。
最后看圈内热议。Hugging Face CEO Clément Delangue 说自己的 P(Doom) 接近零，认为大部分风险来自少数闭门造车的玩家，这与主流 AI 灭绝风险叙事正面交锋。另一边，一篇“现在一切都是 AI 骗局”的文章在 Hacker News 上引发热议，加上另一条吐槽 agent 不可预测的帖子，两条合流指向同一种情绪：开发者对 agent 落地的预期正在回调。
今日观察。今天最清晰的信号是，AI 竞争正从模型能力转向基础设施与信任层，OpenAI 一天之内连发 Images 2.6、收购 Pierre、公布内核漏洞自动化修复，Meta 拿下 Conductor，都是在补 agent 工作流的周边拼图，而不是发布新基座模型。研究侧同样呼应，FlashProve 用密码学证明回答的来源，Stanford 则揭示近半数结论已过期，两者共同指向一个被长期忽视的问题：我们缺乏对模型行为的可验证性。另一条值得警惕的线是物理约束开始反噬，PCB 交期 30 个月、数据中心在选举中全面受挫，算力扩张的政治与供应链成本正在变成硬上限。对 builder 来说，短期最实用的两个动作是：认真评估上下文压缩，长上下文可能被高估了；以及把 agent 的记忆与可观测性当作一等公民来设计。好，今天就聊到这里，我们明天见。
