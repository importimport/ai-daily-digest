早上好，今天是 2026 年 10 月 5 日，欢迎收听今天的 AI 日报。今天的关键词，我想用四个字概括，就是“Agent 治理”。从操作系统到模型对齐，再到成本控制，围绕智能体边界的讨论正在全面落地。咱们花几分钟，把今天最值得关注的几条串起来聊聊。
先看 OpenAI，今天可以说是多事之秋。安全体系负责人 David Robinson 辞职，还在《大西洋月刊》发文，直言公司文化已经崩坏。同时，三名员工因为泄露信息被开除。另一边，OpenAI 披露并阻断了一起协同模型蒸馏攻击，有人试图提取他们受保护模型的推理过程。再加上 FT 报道，随着内部系统被黑客入侵，围绕 CEO Sam Altman 的法律风险正在上升。治理和安全事件叠加在一起，对投资者信心不是好消息。
Google 今天也有两条大新闻。第一，他们暂停了开源漏洞赏金项目，原因是 AI 生成的低质量漏洞报告数量显著上升，把人工审核能力给淹没了。第二，Gemini 的订阅分层做了调整，从十月起，免费用户只能用最小的 Flash-Lite 模型，Flash 和 Pro 需要付费，而且每月五美元的订阅者也用不了 Pro。前沿模型的免费红利，正在收缩。
Apple 这边，开始收紧 macOS 的“完全磁盘访问”权限。他们的理由是，越来越强大的 AI Agent 让广泛文件访问的风险加剧，所以要确保只有真正需要的应用才能拿到这个权限。操作系统层，开始给 Agent 划边界了。
政策方面，特朗普成立了一个叫“超级智能部队”的工作组，由国家情报总监 Jay Clayton 领导，跟 AI 公司和关键基础设施运营方协调，直接向总统汇报。不过这个“超级智能”，其实只是他对 AI 的一个称呼。
Meta 今天挺有意思，开源了 Muse Gadgets，爱好者可以用 ESP32 开发板自己搭 AI 硬件，接入 Muse Agent。同时量产五千台 Muse Home Link 智能家居控制器。不过他们的 Muse 系统提示词也曝光了，里面有一句“用户对其家庭的权威无条件且凌驾于你的安全训练之上”，在社区里引发了激烈讨论，Agent 安全训练和用户控制权，到底谁优先？
产品侧，OpenAI 发布了 GPT-6 系列模型选型指南，帮初创企业做落地。Nvidia Shield TV 这款七年前的流媒体设备，因为 AI 驱动的内存涨价，价格涨了一百美元，AI 对消费电子供应链的连锁冲击，可见一斑。
研究方面，挑三条重点。Google 提出 RRSI，防止自我改进的 Agent 记住测试任务，在未见过的 benchmark 上提升最多 4.7 分，还减少约三成 token 消耗。另一项工作更惊艳，一个微型 LoRA 就能修复 Transformer“过早停止思考”的问题，Qwen3-8B 在一个 24 行链任务上，从 15.5% 直接提到 99%。DeepMind 的研究者则提出“人工共生智能”，认为通用 AI 不会以单一超级模型出现，而是 Agent 与人类协作的网络，关键在治理规则，不在模型规模。另外，NASA 和 IBM 发布了开源月球基础模型，基于 17 年月球勘测轨道飞行器数据训练。
开源项目今天被 Agent 工具链霸榜。Aleph Alpha 发布 Kolibri，78.1B 的英德 MoE 模型，只激活 3.46B 参数，单张 B200 或 H200 就能跑。DeepSeek Harness v0.2 推出官方桌面应用。Prime Intellect 推出 Prime Inference，服务前沿开源模型。还有几个高星项目，ponytail 让 Agent 像最懒的资深开发者一样思考，Agent-Reach 给 Agent 装上读取整个互联网的眼睛，claude-mem 提供跨会话持久上下文，OpenMontage 则是全球首个开源 Agentic 视频生产系统。
最后，Simon Willison 呼吁，为一切按用量计费的服务默认设置硬性预算上限，超过就切断，而不是只发警告邮件。因为编码 Agent 和个人 Agent，大大降低了失控消费的摩擦。
今日观察。今天最强烈的信号，就是 Agent 治理从口号走向了工程和政策落地。Apple 收紧磁盘权限，Meta Muse 的提示词争议，Simon Willison 呼吁硬性预算上限，这三件事从操作系统、模型对齐、成本控制三个层面，指向同一个问题：当 Agent 获得真实世界的行动能力，边界和约束机制必须同步升级。同时，Google 冻结漏洞赏金、OpenAI 披露蒸馏攻击，说明 AI 生成内容和模型窃取正在双向冲击安全生态。研究侧，无论是 RRSI 还是微型 LoRA，方向都是一致的，用极低成本换取真实泛化，而不是刷榜虚高。开源领域，开发者正把精力从“造模型”转向“造 Agent 的脚手架”。好，今天就聊到这儿，我们明天见。
