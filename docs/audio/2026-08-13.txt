早上好，今天是八月十三号，星期四。欢迎收听今天的AI行业播报。今天的内容相当密集，从模型发布到资本动向，再到安全争议，信息量很大，咱们一件一件说。
先看最重磅的。SpaceXAI 发布了 Grok 4.6，在 Artificial Analysis 智能指数上拿到了六十一分，跟 OpenAI 最强的模型打平，但价格便宜了六成以上。更关键的是，在 Agent 任务上它平均只需要五十多步就能完成，而 Claude Opus 5 要一百多步，这个推理成本优势非常明显。可以说，Grok 4.6 用更低的成本做到了同样的事，这对闭源模型的定价体系是个不小的冲击。
另一边，Meta 开源了 Muse Glimmer，一个三百亿参数的多模态 Agent 模型，Apache 2.0 协议，量化之后不到二十个G，可以在消费级硬件上本地跑。这是开源模型第一次在端侧 Agent 全任务基准上达到前沿水平，意义不小。Nvidia 也正式入场万亿参数赛道，正在开发 Nemotron 4，目标是对标全球最好的开源模型。不过说实话，中国实验室已经先达到这个规模了，Nvidia 这次算是追赶者。
说到中国，面壁智能正式启动 IPO，中信证券辅导，端侧模型公司走向资本市场，这也标志着端侧 AI 的商业化获得了资本市场认可。
再来看 OpenAI 这边的动态。创始元老 Brad Lightcap 离职了，他是特殊项目负责人，也是前 COO，在 OpenAI 待了八年，现在要自己创业。核心高管连续流失，组织稳定性确实让人关注。另外 OpenAI 开始在 ChatGPT 里测试广告，目的是支撑免费访问，承诺会明确标注、保持答案独立性、保护隐私。超级 AI 应用转向广告模式，这个动向值得留意。还有一件事，OpenAI 终于发布了 Linux 版的 ChatGPT 桌面应用，补齐了桌面端最后一块拼图，对开发者生态是个好消息。
用户规模方面，ChatGPT 和 Gemini 双双突破十亿用户，Gemini 成了 Google 历史上增长最快的产品。AI 应用正式进入十亿用户时代，入口之争越来越白热化。
不过 Google 内部似乎不太平静。有消息说布林紧急接管了 Gemini 团队，算力分配内耗严重，连 3.5 Pro 都被取消了。创始人亲自下场，说明问题不小。
安全方面有几件事值得警惕。Anthropic 新水印系统引发了用户不满，有人担心水印会暴露他们在工作或学业中使用 AI 的行为。这个争议背后其实是内容溯源和用户隐私之间的张力。另外，有研究团队实现了对 LLM 推理轨迹的窃取攻击，Anthropic、OpenAI、Google 返回的加密 CoT 块可以被重放，弱模型甚至能被越狱去恢复强模型的隐藏推理。这对所有 CoT 加密方案都是个重大威胁。还有一项研究显示，逆向工程 LLM Prompt 已经能达到近乎完美的精度，专有 system prompt 面临严重泄露风险。
政策层面，六大 AI 公司签署了欧盟的 AI 生成内容透明度准则，Anthropic、OpenAI、Google、Meta、Microsoft、Mistral 都参与了。这意味着 AI 内容水印将成为法定要求，开源模型也会受影响。
开源项目方面，今天有几个值得关注的。Meta 的 Muse Glimmer 正式开源，可以在本地跑。Nvidia 开源了 Magpie TTS，低延迟多语言语音 Agent 构建方案，开放权重加完整部署控制。还有 cactus-compute 的 needle，一个只有十四兆的基础模型，面向手机、可穿戴、智能家居和机器人这些微型设备，端侧 AI 覆盖到了最末端的场景。另外 stablyai 的 orca 是面向并行 Agent 群的开发环境，支持桌面、移动和 VPS，今天涨了一千多 star。编码 Agent 的基础设施也在快速成型，herdr 提供运行时环境，paperclip 做企业级 Agent 管理，opencodex 则打破了 Codex 和 Claude Code 的模型锁定，可以灵活切换任意后端。
最后说一句，今天社区里 Qwen 3.8 系列发布在即，2.4T 参数的版本已经出来了，27B 版本也快了，大家都在期待中国开源模型再次刷新上限。
今日观察。今天的核心信号是开源与闭源的攻防战进入新阶段。Meta 用 Muse Glimmer 重新杀回开源前沿，Nvidia 携 Nemotron 4 入场万亿参数赛道，而微软的闭源模型被 DeepSeek 在性价比上碾压——开源模型的竞争力已经从够用变成了领先。与此同时，推理轨迹窃取攻击的曝光给闭源 API 的安全幻觉敲响了警钟，加密 CoT 并不是万无一失。另一个趋势是 Agent 基础设施层的爆发，从运行时到管理平台再到并行开发环境，围绕 Agent 的卖水人生态正在快速成型。最后，欧盟 AI 内容透明度准则获得六大巨头签署，水印和溯源将成为所有模型的法定标配，这对开源生态和开发者工作流都会产生深远影响。
