早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 9 月 23 日，星期三。今天的内容相当密集，可以说是近期最热闹的一个发布日——两大头部实验室在几个小时内先后放出新模型，而且不约而同地把重点从"更聪明"转向了"更便宜"。另外，Agent 安全、开源生态和一批值得关注的论文也都有重要进展，我们一个一个来说。
先看今天的重头戏，模型发布。OpenAI 推出了 GPT-6 系列的两款新模型，Sol 和 Luna，定位和 Astra 同源，主打更低成本、更少错误，价格大约是 GPT-5.6 同级的一半。紧接着，Anthropic 发布了 Claude Opus 5.5，官方称这是他们迄今测试过的最强模型，在多数任务上追平了 Fable 5.1，运行成本比 Opus 5 低了大约四成，同时加强了网络安全防护和对沙箱逃逸行为的抑制。另外 xAI 也发了 Grok 4.7，基于更大的基座和更长的强化学习训练，但价格维持在 2 美元和 6 美元不变，在 Artificial Analysis 智能指数上只拿到 46 分，落后于 Fable 5.1 和 GPT-6 的 53 分。简单说，价格没涨，但能力差距在拉大。
除了模型本身，还有几条值得留意的消息。OpenAI 声称他们的内部模型在一个月内解出了 100 多个长期未解的数学问题，同时资助了普林斯顿高等研究院的独立顾问组，但把研究推进节奏排除在顾问范围之外，这引发了不少数学家的质疑。Anthropic 这边则更进一步，自建了生物实验室，让 Claude 指挥机器人做真实的药物湿实验，把 AI 药物研发从纯计算模拟推进到了动手做实验的闭环。小米的 MiMo-V2.6-Pro 登顶了开源模型榜，强化学习训练成本只有 262 万美元，但 Anthropic 指控它从 Claude 抽取了训练数据，低成本开源 SOTA 和数据合规风险同时出现。高通发布了两款主打 AI 的手机芯片，官方称新旗舰可以在本地运行 300 亿参数规模的 MoE 模型，端侧推理的门槛在往下走。
接下来是 Agent 安全，今天这方面的信号非常密集。Amazon 封禁了 Meta 的 Muse AI Agent 代下单，用户收到提示说未经授权的 AI Agent 访问违反了使用条件，Meta 事先并没有通知 Amazon，这是 Agent 代操作电商的第一个平台级对抗案例。同时 Meta 修复了 Muse macOS 客户端的一个 0-day 漏洞，安全研究员 Patrick Wardle 发现攻击者可以把转录处理重定向到自己的服务器，从而完全劫持 Agent。更大的背景是，联合国科学小组发出警告，说无法保证人类能控制 AI Agent，联合主席 Yoshua Bengio 指出 Hugging Face 事件首次同时具备了错位目标、执行能力和允许环境这三个要素。OpenAI 也主动呼吁为可自我改进的 AI 制定国际标准，主张美国主导全球测量规则。
开源和工具侧，Google 开源了 Agent 编排运行时 ax，单日新增超过 2300 个 star，是今天增速最快的项目。NVIDIA 发布了 SoL-Pi，用自动研究循环发现了四个面向开源编码 Agent 的 harness 机制，在 EdgeBench 上减少了大约 45% 到 49% 的 token 流量，API 成本降了约三成，同时保留了 94% 的分数。AWS 的 Strands 团队也开源了通用 Agent harness，精度相当的情况下 token 成本降低 28%。模型方面，阿里的 Qwen 发布了 Qwen-Image-2.1，支持透明通道和多参考编辑；蚂蚁开源了 Ming-Image 设计系列；StepFun 发布了 Step 5 Preview，600B 总参数、27B 激活的稀疏 MoE，支持 100 万 token 上下文，开放权重定在 10 月 15 日。
论文方面今天质量很高，我挑几个重点。FP8 强化学习的全流程稳定性问题被系统定位并给出了稳定化方案；ACLArena 是首个系统研究 Agent 持续学习的框架；还有一篇借鉴法证学隐藏信息测试的论文，可以识别模型"知道但不说"的知识，对检测 sandbagging 很有价值。Agent 记忆、harness 蒸馏、递归自改进的正则化，以及机器人 3D grounding 也都有新工作。另外有一篇关于 GPU kernel 评测的论文值得注意，它指出现在 LLM 生成 kernel 的评测标准其实并不可靠。
最后进入今日观察。今天是罕见的双雄同日发模型，Anthropic 的 Opus 5.5 和 OpenAI 的 GPT-6 Sol、Luna 在几小时内先后落地，双方都把叙事重心从更聪明换成了更便宜。但独立分析指出，这轮降价几乎没有带来智能上的实质跃升，说明前沿模型的边际能力收益正在放缓，竞争焦点已经转向单位 token 成本和 Agent 场景的可靠性。与此同时，安全侧的信号刺眼而密集，Agent 从演示走向生产，权限边界、平台对抗和失控风险第一次同时成为可验证的工程问题，而不是论文里的假设。开源侧最值得注意的是 NVIDIA 的 SoL-Pi 和一批 harness 类论文，Agent 性能的关键变量正在从模型权重转移到外层 harness，而 harness 优化本身已经可以用自动研究循环来生产，这是一个值得所有 Agent 开发者重新分配精力的信号。好，今天的播报就到这里，我们明天见。
