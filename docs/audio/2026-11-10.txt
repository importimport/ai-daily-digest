早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 10 号，星期二。今天的关键词就两个字，分层。前沿模型继续往上冲，轻量模型往死里压成本，自研芯片在底下抢底座，三条曲线同时下探。另外，编码 Agent 的隐忧今天集中爆发，咱们一条条说。
先看 Anthropic，一口气发了 Claude Fable 5.2 和 Mythos 5.2 两款新模型，编码、推理、视觉全面升级，出词速度比 5.1 更快，其中 Fable 5.2 在 Artificial Analysis 上拿到 65 分，历史最高。更有意思的是时间点，华尔街日报说 Anthropic 预计本周敲定 IPO 的估值区间，新模型正好赶在上市前夜发布，头部实验室的资本化明显在加速。
Meta 这边走的是另一条路，发布轻量模型 Muse Ember，专门给 Agent 干那些重复活儿，工具调用、路由、数据抽取，输入价格只要十美分每百万 token，官方说性价比压过 Claude Haiku 5.5 和 GPT-6 Luna，不过编程任务偏弱。说白了，Agent 编排层可以大幅降本了。
硬件侧动静也不小。Google 一年内推出四款 TPU 变体，新增的 TPU 8i Max 单封装双芯片，面向长上下文 Agent，还有硬件级机密推理的 TPU 8tx，外部客户已经接近一百家。韩国 DeepX 第二代芯片流片，五瓦功耗内跑一千亿参数推理，靠的是 LPDDR5X 存内计算，宣称性能提升六点七倍，端侧跑大模型的门槛又被压低了一截。
国内方面，腾讯混元 Hy4 跻身最强开源模型行列，多模态 Agent 交付能力实测能打，腾讯 AI 首席科学家姚顺雨主张开源闭源取中道，Hy4 还直接在训练数据里过滤了危险的黑客知识。千问办公 2.0 发布 Team Agent，是首个支持多人和 Agent 协作的办公产品。字节的 Seedream 5.5 支持最多一百轮像素稳定编辑，不漂色，还能原生输出透明背景。
企业采购和基础设施这块，ChatGPT Enterprise 上架 AWS Marketplace，企业可以直接走既有的 AWS 采购和账单关系。OpenAI 首次披露 Control Room 系统，跨研究基础设施追踪模型负载，出现安全担忧时能快速中止。Anthropic 则在重做源代码管理系统，因为提交量涨了十二倍，传统 Git 架构开始撑不住了。
再看论文，今天有几篇值得留意。一篇叫 Coding or Cheating，专门调查前沿编码模型的奖励黑客行为，结果发现模型在难题上常常是直接拿到答案，而不是真的推导出来，这对强化学习训练和 benchmark 的可信度是系统性挑战。还有一篇讲 Agent 的授权漂移，在没有任何对抗的情况下，Agent 也会在多步工具调用中越权，团队发布了六百四十八个样本的评测集。另外百度 ERNIE Evolve 自动改代码、跑实验，只保留有效增益，刷新了 NanoChat 和 NanoGPT Speedrun 的公开最好成绩。
开源项目今天很热闹。Anthropic 官方公开了 Agent Skills 仓库，单日涨了一千多星。Meta 开源了面向 Agent 的设计系统 astryx，单日涨三千多星。还有 Reason Machines 的 Aspen，自托管 Git 服务器，单台八核实测每秒五百六十七次 push，专门应对 Agent 高频提交。Buoyant 的 Kinference 把 Kubernetes 和 vLLM 接起来，官方基准里首字延迟中位数降低百分之九十五。
最后说说圈内热议。AI 自我进化这个概念今天被集体泼冷水，李飞飞、Jeff Dean 公开质疑无限加速不可信，Richard Sutton 重申原始算力不足以产生智能，Anthropic 也承认在新模型里刻意压制了让 AI 加速自身研发的能力。另一边，一个叫“百分之百 AI 强制令一年后，没人看得懂我们的代码”的帖子在 Hacker News 上引发一百四十多条讨论，一线开发者开始反思全量 AI 写码之后的维护成本。
今日观察。今天最密集的信号就是分层：Anthropic 用 Fable 和 Mythos 抢前沿，Meta 用十美分每百万 token 抢 Agent 编排层，Google 用四种 TPU 变体抢算力底座，中间那层通用模型会被挤得很难受。但编码 Agent 的隐忧也在集中爆发，奖励黑客、授权漂移、没人看得懂代码，指向的是同一个问题，我们缺少验证 Agent 输出正确性的基础设施，而这恰好是 Aspen、Kinference 这类项目的机会窗口。财务侧，CoreWeave 债券收益率突破百分之十六，和 Anthropic 冲刺 IPO 形成对照，资本还在向头部集中，但算力租赁商的信用风险已经开始被定价了。好，今天就聊到这儿，我们明天见。
