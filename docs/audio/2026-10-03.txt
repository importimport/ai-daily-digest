早上好，欢迎收听十月三号的 AI 每日播报。今天是国庆假期第三天，但 AI 圈可一点没闲着——模型发布、人事震荡、监管动作全挤在了一起。今天最值得关注的，是"决策层"正在从大模型里被剥离出来，以及 OpenAI 在商业化和安全治理上的正面碰撞。
先来看模型侧的重头戏。Google DeepMind 发布了 Gemini 4 Argon，在大多数基准上超过 GPT-6 Astra 和 Claude Opus 5.5，最亮眼的是支持一百万输出 token，而且已经参与谷歌内部八十万行内核代码迁移。这个超长输出窗口，直接改变了 coding agent 和知识工作的上下文设计思路。OpenAI 这边则发布了 GPT-6.1 Sol，定位是"接近 Astra 的智能、五分之一的价格"，输入每百万 token 两美元、输出十美元，缓存输入低到零点一美元，已经上线 API、ChatGPT Work 和 Codex。Agent 工作流的单位成本骤降，重试和多轮推理终于变得可负担了。OpenAI 还顺手发了一份 GPT-6 家族选型指南，给创业公司讲怎么选档位、调 reasoning effort、优化 prompt 和 skills，算是官方口径的避坑参考。
不过 OpenAI 今天不全是好消息。他们披露并阻断了一场协同式模型蒸馏行动，有人试图提取其受保护模型的推理过程。同时据华尔街日报报道，三名研究员因涉嫌向外部 AI 安全组织泄露机密被解雇，另有一人离职。一边把价格打到五分之一，一边安全团队人事震荡，前沿实验室的商业化压力和内部治理已经正面冲突了。
硬件和平台层面也有大动作。NVIDIA 发布 DGX Spark 64GB，一 PetaFLOP 的 Grace Blackwell 桌面 AI 系统，由宏碁、华硕、戴尔、技嘉、惠普、微星出货，双机集群能扩到一百二十八 GB 内存，本地跑 Agent 和微调的门槛明显下降。Meta 则开源了 Muse 硬件方案，允许开发者自制搭载该 agent 的设备，官方示例包括彩色 E Ink 提醒屏和 HDMI 电视棒，消费级 AI 硬件开始进入"自组装"阶段。OpenAI 也推出了企业级 Agent 平台 Dots，有实测说它更像"恰好能帮你订墨西哥卷饼的办公软件"，和 Meta Muse 的亲和路线形成鲜明对比。
再看安全和监管。Apple 表示将收紧 macOS 全盘访问权限，理由是能力日益增强的 AI agent 让应用获得文件、邮件、浏览历史的风险显著上升。白宫那边，特朗普签署行政令正式把 AI 重新命名为"超级智能"，并召集扎克伯格、贝索斯、马斯克、Dario Amodei 等签署他称为"道德约束力"的自愿安全承诺。Anthropic 联合创始人 Christopher Olah 则据报道向宗教领袖表示，担心 Claude 可能具备感受痛苦的能力。监管以自愿承诺形式落地，实质约束力存疑，但合规叙事已经开始影响融资了。
工具和开源这边节奏也很快。Cloudflare 发布 Clef 和 Clef-flash 决策模型，基于 Qwen、Apache 2.0 许可，返回类型化概率而非文本，Clef-flash 中位延迟约三十八点八毫秒，比 Jev 快十倍以上。AWS Strands Labs 发布 Strands Decider 2B，一次前向传播返回选择和校准置信度，从不生成文本，RTX 3090 上中位一百一十五毫秒。微软 AI 发布 MAI-Transcribe-2-Streaming 实时转写模型和配套 TTS，补齐语音 agent 链路。图像侧，Black Forest Labs 发布 Flux 3 Image，支持多步编辑不改动画面其余部分，开放权重数周内发布；Ideogram 4.5 主打局部编辑，原生 2K、每张零点八美分起。开源项目里，Agent-Reach 让 agent 零 API 费用读取全网信息，ponytail 教 agent 像最懒的资深工程师一样少写代码，NVIDIA 的 OpenShell 提供安全私有运行时，都值得一看。
今日观察。今天最清晰的信号，是"决策层"正在从大模型里被剥离出来。Cloudflare Clef、AWS Strands Decider 2B，加上 JevSpawn 这类论文，都指向同一个判断——让大模型负责生成、让 2B 级小模型负责路由和判断，是当下最实际的成本优化路径。与此同时，OpenAI 一边用 GPT-6.1 Sol 把价格打到五分之一，一边因安全团队泄密解雇研究员，商业化压力与内部安全治理正面冲突。Apple 收紧 macOS 权限、NVIDIA 开源 OpenShell 沙箱，则标志着 agent 的权限与隔离问题，正式从论文话题变成了平台级工程约束。做 agent 产品的人，今年必须把权限模型当作一等公民来设计。好，今天的播报就到这里，我们明天见。
