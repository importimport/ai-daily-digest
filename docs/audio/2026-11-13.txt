各位听众早上好，今天是 2026 年 11 月 13 日，欢迎收听 AI 日报。今天最重磅的消息，是 Nvidia 掌门人 Jensen Huang 突然辞职，整个 AI 硬件和开源生态都被震了一下；与此同时，Google 一天之内连发多条产品线，攻势相当密集。我们一条条来聊。
先说 Nvidia。因为涉及一名疑似中国情报人员的婚外情调查，Jensen Huang 即刻辞去了 CEO、总裁和董事职务，由 Colette Kress 出任临时 CEO，公司市值一夜蒸发约 1.4 万亿美元。这件事的影响远不止人事变动：Nvidia 的路线、对开源模型的承诺、对华供货政策，全都进入了不确定期。紧接着，美国国会民主党人对 Nvidia 启动调查，重点盯着对华销售以及 Huang 和 Trump 之间的所谓"交易"，这是间谍传闻爆发以来的第二起国会调查，芯片出口的合规风险明显上升。
更让开源社区紧张的是，Huang 在任时推动的 Hugging Face 收购、开放权重模型、反对限制游说，都可能随领导层更替而转向。Hugging Face 的 CEO 已经公开表态要继续为开源 AI 而战，但社区的反应是"听起来不太妙"，不少人建议尽快备份常用的数据集和模型权重。一句话，开源生态最大的硬件靠山和托管中枢，同时悬了。
再看 Google。它发布了 Gemini 4 Hydrogen，定位是 Gemini 4 家族里最便宜的成员，擅长拆解多部分问题、错别字和高度具体的请求，已经接入搜索、Gemini App 和 Antigravity。基准测试上，Hydrogen 反超了更大号的 Argon，逼近 Claude Sonnet 5.5 而且更便宜，但单任务成本大约是 GPT-6.1 Sol 的 2.5 倍，agentic coding 还是偏弱，所以选型不能只看分数。另外，Google 还推出了 Gemini Decisions API，一次可以对最多 1000 个是或否、多选和评分制问题返回校准概率，支持文本、图像、音频、视频和 PDF，输入价格是每百万 token 十美分，分类和打分类任务可以用极低成本替代通用大模型。工程层面，PyTorch 现在可以原生跑在 TPU 上了，多硬件的迁移门槛明显下降。
Anthropic 这边，Claude Meetings 上线，Claude 可以直接加入 Google Meet，实时生成文档、白板和会议纪要，目前是面向团队版和企业版的 Beta。同时 Anthropic 启动了 IPO 路演，估值缩水 6000 亿美元，路演视频里首次披露了它跨 AWS Trainium、Google TPU、NVIDIA 和 AMD GPU 的异构算力策略，这对头部实验室控制成本很有参考价值。算力侧，Nebius 公布了 400 亿美元的基础设施扩张计划，靠客户预付款和贷款融资，但微软相关数据中心延期，让这种杠杆式扩张的现金流风险受到质疑。
研究和开源方面，有几个值得关注。OpenAI 的安全团队系统研究了前沿模型"隐藏思考"的成因，发现是架构选择和强化学习等四个训练环节导致思维链可监督性下降，也就是说透明性流失是能力和成本权衡的结果，可解释性得在设计训练目标时就考虑进去，而不是事后审计。Google DeepMind 的 AlphaGenome 2 把基因组预测推进到单细胞类型分辨率，识别出的疾病相关变异约为前代两倍；AlphaProof Code 更是四周就完成了 Signal 加密核心的形式化验证，写出超过 600 万行 Lean 证明代码，只有约百分之一需要人工复核。开源项目里，Meta 开源了面向 Agent 的设计系统 astryx，OpenAI 放出了 Codex Security 的命令行工具和 SDK，Meta FAIR 的 e-means 已经并入 FAISS，向量索引构建能快一个数量级，做 RAG 的团队可以直接受益。
最后提两个落地层面的信号。美联航以网络安全风险为由，禁止 AI Agent 订票和管理订单；而 ScrapeBench 这个新基准实测发现，多数 Agent 在遵守网站服务条款和 robots 协议上的合规率低于百分之五。这说明 Agent 商业化的瓶颈，已经从模型能力转向了平台风控和法律责任。
今日观察。今天真正的主线不是某个模型，而是 Nvidia 权力真空引发的连锁反应：市值蒸发、国会二次调查、Hugging Face 归属悬而未决，开源生态最大的硬件和托管靠山同时进入不确定期，团队应该把"模型与数据可迁移性"当作本周的工程任务，而不是风险备忘。与之对照，Google 一天之内用 Hydrogen、Decisions API、AlphaGenome 2 和 AlphaProof Code 四条线同时推进，说明在对手动荡期抢占开发者心智，最有效的手段仍然是压低单位任务成本。OpenAI 关于思维链透明性流失的自曝也值得警惕，当少写思考能换来能力和成本优势时，可解释性不会自动到来，只能被设计进去。好，今天的日报就到这里，我们明天见。
