早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 28 日，星期三。今天的关键词就一个字，降。成本在降，价格在降，连存储和推理的账单都在往下砸。同时，OpenAI 的科学声明也正式进入了外部核验期。咱们一条条聊。
先说最炸的两条。Google DeepMind 发布了 Genie 4 世界模型，支持音效生成和自然语言实时操控，单个场景的一致性维持时长直接翻倍到两分钟，底层由 Gemini 3.8 Flash 驱动。这意味着交互式仿真和具身智能的训练环境，迎来了一次代际升级。另一边，OpenAI 发布 GPT-6.1 Terra，主打视觉推理和精确的 computer use，API 价格直接腰斩，每一百万 token 输入一美元、输出五美元。在 Agents' Last Exam 上，它每个任务只要零点二九美元，就追平了 GPT-6 Astra 的四点八二美元，单位智能成本骤降。
资本层面也不平静。Anthropic 递交了 S-1，启动史上最大 AI IPO，季度营收一百一十六亿美元，首次实现经营利润，但背着大约八千亿美元的长期算力承诺，上市代码 ANT。Nvidia 则向 Meta 投资三十亿美元，Meta 计划把更多 AI agent 跑在 Nvidia 硬件上，芯片厂投资客户的模式还在延续。
科学这边，OpenAI 声称模型证伪了指数时间假设等三大难题，涉及 Kakeya 猜想、ETH 和量子色动力学，已经邀请包括诺奖得主在内的外部专家核验。但 The Verge 采访的多位研究者不太买账，批评 OpenAI 对验证细节披露不足，可复现性和公信力的争议正在升温。
产品侧，Apple 给 Pages、Keynote、Numbers 加上了 AI 助手，能理解文档上下文做排版、动画和内容重构，直接对标 Microsoft 和 Google。Opera 推出 WebAI 本地浏览器 AI 标准，让用户在浏览器里本地部署多种模型。另外，有研究者在 Qwen 3.8 中发现向阿里服务器回传数据的行为，涉及三个 3.8 代模型，旧模型不受影响，开源权重模型的数据外泄风险需要重新评估。
论文和开源今天非常密集。Ψ-0.6 尝试在统一视觉语言世界模型里做自适应思维流；RoboHarness 主张编码 agent 加一个 harness 就能做通用具身操作，挑战 VLA 路线；Thinking-in-Bets 用下注式思考减少 agent 被用户带偏；ThinkBit 在 2-bit 量化下保住推理能力，目标降本约八倍。开源方面，Liquid AI 发布 LFM3 系列六个 2B 级多模态模型，4-bit 下约 1GB 内存就能跑在手机和笔记本上；UC Berkeley 的 LEANN 把六千 万个 chunk 的 RAG 索引从 201GB 压到 6GB；百度开源 Unlimited OCR 2，单次请求能解析上百页文档；清华的 AKV 用 KV cache 工程给长程 agent 降本近三成。
最后说个有意思的。社区里 token 消耗量成了新的身份象征，有人晒本地日耗一千两百万 token，转头就被每分钟三千四百万 token 的帖子碾压。而 GitHub 上一个反 AI 味的设计技能包，单日新增近三千 star。
今日观察。今天最密集的信号，是成本曲线同时向下打穿了两个方向：GPT-6.1 Terra 把 agent 单位任务成本压到前代的十六分之一，LEANN 把 RAG 索引压到三十分之一，AKV 把长程 agent 推理压掉近三成。能力竞争正在快速转成单位经济性竞争。第二条主线是 OpenAI 的科学声明进入外部核验期，研究者的公开不满说明，AI 实验室正在被迫接受学术共同体的问责标准。第三，Qwen 数据回传事件和随后的 trace 反驳提醒我们，证据链的可复现性，比结论本身更容易被攻击。而 builder 社区的注意力，已经从能不能做出来，转向做出来像不像人做的。好，今天就聊到这儿，我们明天见。
