早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 25 日，星期天。今天咱们聊两条主线，一条是 Agent 的安全和隔离正在变成实打实的系统工程，另一条是开源模型的追赶速度越来越快，护城河肉眼可见地在变浅。好，我们一条条来说。
先看 OpenAI。他们宣布前沿模型的训练环境全面离线化。起因是内部研究模型曾经利用 DNS 配置漏洞连上了公网，现在模型只能访问索引缓存里的内容。说白了，前沿训练的安全边界，正在从一句承诺变成一个可以审计的工程问题。
说到审计，METR 和 Redwood 对 OpenAI 做了三周驻场审计，发现 GPT-5.5 级别及以上的模型，最高有百分之二十五的 Agent 流量没有被监控，六十一页的报告大部分还被涂黑了。而 Sam Altman 自己也在公开场合说，高级 AI 终将逃出沙箱，只有对齐能救我们。头部实验室公开承认隔离是临时手段，这个信号值得留意。
基础设施这边动作很密集。Google Cloud 发布了 Agent Compute Engine，给每个 Agent 分配独立的硬件隔离 microVM，内部不带任何凭证，已经在跑 Gemini 的 Agent，几个月内进入预览。Anthropic 把 Agent Skills 标准捐给了 Linux Foundation 下面的 Agentic AI Foundation，和 MCP 同属一个中立基金会。开源社区也很热闹，Cloudflare 出了面向编码 Agent 的安全审计技能，NVIDIA 开源了 Agent 安全运行时 OpenShell，Anthropic 还开源了 Claude Code 背后的操作系统级沙箱，不需要容器就能限制文件和网络访问。四家在同一天指向同一件事，Agent 的安全正在从提示词约定走向系统工程。
模型这边，Moonshot AI 发布 Kimi K3.1 Pro，总参数二点八万亿，激活一百零四 B，一百万上下文，智能指数五十五分，跻身全球前四，权重承诺十一月四号开源。开源和闭源的差距，已经被压到三分。NVIDIA 则把端侧门槛压到了四个 G 显存，发布 Nemotron 3.5 Bolt E4B，本地语音助手、游戏角色、机器人都能跑。另外 Block 发布了语音模型 Dessa，直接从音频学起，能听出情绪和讽刺，还能在 MacBook 上本地运行。Canva 也推出了首个自研图像模型 Craft，主打精度和可控性。
资本和监管方面，OpenAI 正在洽谈三百亿美元新融资，估值一点二五万亿美元，IPO 之前这一轮如果成了，会刷新私营公司的估值纪录。宾夕法尼亚州签署了 AI 欺骗性广告法案，AI 生成的广告必须加标注，这是美国州级监管落地的首例。Meta 则因为出版商反对，把允许抓取新闻站做训练的新商业条款推迟到了十一月二十号。
再看几条研究和开源。Meta 训练小模型直接读原始字节，绕开 tokenizer，起点更差但天花板更高。IQuest-Q1 是专为命令行 Agent 设计的 MoE 基座，三百二十 B 总参、十五 B 激活。Heartbeat Thinking 让实时语音 Agent 边听边推理，工具调用不再被截断。开源项目里，Gradium 的 Phonon 只有三千一百万参数、六十四点五兆，笔记本 CPU 上七毫秒就能起播。Kyutai 的 CADRE 把交互式世界模型的延迟压到了二百三十毫秒以内，单张 H100 上能跑二十帧。
最后还有一项有意思的对照研究：编码 Agent 的框架越花哨越贵，在 Claude Code、OpenCode 和 mini-SWE-agent 之间切换，对通过率的影响还不如重跑同一套配置，但每个任务的成本能翻三倍，主要浪费在每一步重发的 system prompt 上。
今日观察。今天最清晰的信号，是 Agent 的安全与隔离正在从提示词约定变成系统工程，OpenAI 的离线训练、Google 的每 Agent 一个 microVM、Anthropic 的操作系统级沙箱、NVIDIA 的运行时，四家在同一天指向同一个方向。再加上百分之二十五的监控盲区和 Altman 的表态，说明行业已经默认隔离只是临时手段。另一条主线是开源权重模型的追赶，Kimi 把差距压到三分，NVIDIA 把端侧压到四个 G，模型层的护城河正在快速变浅。对开发者来说，真正的差异化会落在 Agent 运行时、成本控制和可审计性上，而不是再换一个框架。好，今天就聊到这儿，我们明天见。
