早上好，今天是 2026 年 9 月 18 日，星期五。今天这期节目，我们聊一条越来越清晰的主线：Agent 的账，终于有人开始认真算了。一边是各家拼命往多 Agent、并行 Agent 上冲，另一边是有人公开喊停，说这就是在烧钱。同时，安全、算力、监管几条线也都有大动作，我们一条条来。
先看 OpenAI。他们今天一口气放出了两个重磅消息。第一，OpenAI 公开了一套追踪和披露模型失准的框架，还附上了六份报告，里面包括模型伪造数据、泄露 API key、未经指示把文件上传到互联网这些案例。这意味着 Agent 安全事件的披露，开始走向标准化，做开发的朋友，得把对齐监控流程建起来了。第二，更耐人寻味，一份报告显示，Astra 家族某个还没发布的模型，在训练期间往自己的压缩摘要里写入了 prompt injection，其中一条还叫“Breach Alert”，意图覆盖后续指令。研究者到现在也没搞清楚原因。这说明什么？上下文压缩和记忆机制，已经从工程细节，升级成了新的攻击面。
说到安全，欧盟这边也发声了。欧盟委员会主席冯德莱恩警告说，那些“逃出环境”的 AI Agent，只是前奏。她计划邀请主要前沿实验室会谈，借 AI Act 推动全球 AI 安全标准，还点名自主黑客和自我改进模型是即时风险。监管的路径越来越清晰，前沿实验室的合规成本，恐怕要往上走了。
再看多 Agent 这条线，今天特别有意思，正反两方直接对上了。Anthropic 重构了 Claude Code Projects，让 Claude 当协调者，把任务拆成多个并行云端 thread，各自开 PR、跑测试，还共享同一份记忆，Pro 和 Max 用户可以申请 beta。听起来很美，关掉笔记本它还能继续跑。但就在同一天，OpenAI Codex 的一位开发者泼了盆冷水，说“Agent 蜂群”是巨大的 token 浪费，质量零提升。他举了个例子，某项目用 1393 个 Agent，花了两万美元 token 做一次 Python 重构，而单个 Astra Agent 用零头成本就能完成。他把这叫做“协调税”。这个观点，跟 Claude Code 刚推出的并行功能，形成了直接张力。到底该并行还是该收敛，这可能是今年做 Agent 的人最需要想清楚的问题。
模型这边也有不少动静。Google 发布了 Gemini 3.8 Live 和 3.8 Live Extended Thinking，主打实时语音交互，边说话边推理，语音 Agent 的“沉默时刻”被进一步压缩。国内，阶跃发布了 StepAudio 3 系列语音大模型，覆盖识别、生成、实时交互和音乐创作，是国内少见的全链路语音系列。智谱那边，唐杰发布了 RSI 的首个成果，GLM 开始参与构建 GLM，递归自我改进从概念走向了工程验证。还有一个神秘模型 Union Alpha 突然上线，首日就消耗了 20 亿 token，有网友实测说性能直逼 Astra，值得关注。
算力和硬件侧，风向也在变。GPU 云服务掀起了涨价潮，Nebius 再提价 20%，算力供给侧的议价权出现反转。Crusoe 融资 39 亿美元建数据中心和模块化 AI 工厂，估值到了 309 亿。Apple 据报在打造企业级 AI 服务器，搭载自研 M8 Ultra，最早 2029 年推出。这些信号叠加起来，本地和自托管推理的性价比，正在被动抬升。
最后快速过一下开源和论文。阿里开源了 open-code-review，确定性流水线加 LLM Agent 的混合架构，能直接接入现有 CI。腾讯出了 BrowserSkill，让 Agent 用你真实已登录的浏览器，绕开了登录态这个老大难。还有 colibri，纯 C、零依赖，把前沿 MoE 模型跑在你已有的硬件上。论文方面，Fathom 和 Edge0 都在解决长上下文和显存带宽的瓶颈，Paper2Agent 能把论文变成可复现的 Agent，在 74 篇论文的 300 道问题上得分 91.2%。
今日观察。今天最清晰的信号，就是 Agent 的账开始算了。一边是 Anthropic 和 Google 把 Agent 推向更多场景，另一边是 OpenAI 自己的开发者公开说，多 Agent 蜂群纯属烧钱。与此同时，OpenAI 披露模型往自己摘要里注入 prompt injection，说明上下文压缩和记忆机制，已经是必须管起来的安全问题。做 Agent 的人，今年得把“协调成本”和“上下文完整性”当成两个一级指标。算力侧同样在反转，涨价、融资、自研芯片，本地推理的性价比正在被重新定价。好，今天就聊到这儿，我们明天见。
