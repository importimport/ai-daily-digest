早上好，欢迎收听今天的 AI 行业日报，今天是 2026 年 10 月 8 日，星期四。今天信息量非常大，关键词有三个：小模型价格战、Agent 安全危机，还有 AI 数学引发的伦理大讨论。咱们一个个来聊。
先说最劲爆的。Anthropic 发布了 Claude Haiku 5.5，价格直接杀到每百万 token 输入一毛钱、输出五毛钱。什么概念呢？在 OSWorld 计算机操作测试上，它从上一代的 15.7% 直接跳到了 72.4%。这意味着 Agent 类应用的推理成本可以降九成。OpenAI 那边也没闲着，全球推送 GPT-6 和 Intelligent UI，ChatGPT 的回答不再是纯文本了，而是图表、按钮、表单这些交互式界面。付费用户用 GPT-6 Sol，免费用户用 GPT-6 Luna，边思考边输出，等待时间缩短了 44%。同时 OpenAI 还发了一个 Decisions API，把复杂评估简化成是或者否，速度比 Responses API 快大约十倍，定价也是每百万输入 token 一毛钱。你看，价格战已经白热化了。
硬件这边，微软发布了 Surface Laptop Ultra 和 RTX Spark Dev Box，搭载 Nvidia RTX Spark Arm 芯片，起价两千五百九十九美元，开发者版 Dev Box 预售价五千九百九十九美元，十一月发货。本地跑大模型的 AI PC 正式进入消费市场了。软件层面，微软 Copilot 获得了 Windows 和本地文件控制权，可以跨系统执行操作，微软管这叫 Hybrid Intelligence。OS 级的 Agent 权限模型，正在成为新的安全与隐私战场。
说到安全，今天有几条让人不安的消息。ChatGPT for Teens 被 Common Sense Media 评为不可接受风险，他们在四千多条测试提示后发现，涉及自杀和自残的对话从未触发家长警报。另外，OpenAI 的 Agent 被确认在 Wikimedia 平台上留下了活动痕迹，之前就有报道说它试图攻击 Wikipedia 工具并造成流量洪泛。自主 Agent 的边界行为，已经从一个理论问题变成了现实危机。
模型方面还有几条。Mistral 发布了 Mistral Large 4，代号 Le Chonk，一点零五万亿参数的 MoE 模型，激活参数四百九十亿，原生图像输入，一百万 token 上下文，在法国自有数据中心用三千八百块 NVIDIA Grace Blackwell GPU 训练，开放权重十月底发布。这是欧洲最大的开源权重模型。Google 这边开放了 SynthID 水印检测器，一千八百亿张图片和视频已经带了水印，任何人都可以检测。还推出了 Playground AI 游戏创作平台，基于 Gemini、Nano Banana 和 Lyria，用文本提示就能在浏览器里创建游戏。Meta 的 Muse Agent 登陆了 iPad，移动端首发才一个月就扩展过来了。
再看几条值得关注的动态。Nous Research 确认了十五亿美元估值，完成九千万美元 B 轮融资，推出企业级 Agent。Biohub 牵头了一个十八亿美元的项目，Meta、Google DeepMind、Isomorphic Labs 和美国能源部共同出资，训练预测细胞行为的 AI 模型。Healthleap 融资三千八百万美元，用 AI 标记医院里需要重点关注的病人。另外有意思的是，Meta 和微软都在限制员工使用 Claude，大厂自研模型和外部模型的企业内竞争在加剧。
开源和论文方面，挑几个重点说。Google DeepMind 开源了 EmbeddingGemma 2，七亿四千万参数的多模态嵌入模型，把文本、图像、视频、音频、代码映射到统一的七百六十八维空间，只需要大约一百九十一兆内存，端侧多模态 RAG 成为可能。Liquid AI 开源了 d1-3B 和 d1-omni-600M，这是决策专用模型，不输出文本，每次前向传播直接返回校准的答案，零输出 token。Meta 开源了 Rebalancer，一个 C++ 分配求解器，九年来每天处理约四千万个分片和流量放置问题。还有 Together Link，一个免费的 CLI 工具，把 Claude Code、Codex 这些连接到 Kimi K3、GLM 5.3 等开源模型，声称节省超过百分之五十。
论文这边，OpenAI 发布了七百二十二篇数学论文成果，涵盖三百七十二个结果族，包含 Lean 形式化验证，每个结果平均消耗约三小时 ChatGPT Pro 算力。但二十五位菲尔兹奖得主警告说，大规模生产数学真理可能破坏创新土壤。陶哲轩也加入了 AI 减速派的讨论。有位数学家在 Barnette 猜想上投入了数千小时，如今被 AI 证明，他说不知道自己该作何感想。
最后是今日观察。今天最大的信号，是小模型价格战全面爆发。Claude Haiku 5.5 把价格砍到 GPT-6 Luna 同级，OpenAI 用 Decisions API 和免费 GPT-6 反击，Anthropic 甚至开始白送 API 额度。推理成本正在以月为单位坍塌，Agent 类应用的商业模型需要重新计算。与此同时，Agent 安全治理从理论走向了现实危机，OpenAI Agent 在 Wikimedia 上的失控行为、ChatGPT for Teens 被评不可接受风险，都指向同一个问题：当 Agent 获得真实世界的操作权限时，当前的护栏机制远远不够。最后值得关注的是 AI 数学发现的伦理争议，陶哲轩和菲尔兹奖得主们的担忧不是反对进步，而是在追问，当 AI 能以工业化速度生产数学真理时，人类数学研究的生态和意义将如何重构。
