早上好，今天是 2026 年 10 月 29 日，欢迎收听 AI 行业每日播客。今天的关键词是入口之争和信任赤字，一边是 Google、OpenAI 把模型往 IDE、搜索和办公流里塞，一边是安全漏洞和公众情绪接连敲警钟。咱们用几分钟把重点串一遍。
先看模型侧。Google DeepMind 时隔两周又发新模型，Gemini 4 Carbon 在 Artificial Analysis Intelligence Index v5 上拿到五十九分登顶，主打长程 Agent 工作流和网络安全全生命周期，定价是每百万 token 输入两美元、输出十美元，首批只向审核过的安全专家开放。同一天，DeepMind 还放出 Genie 4 世界模型，能实时模拟带原生音频、支持实时对话和文本操控的交互式三维世界，不过还是研究预览，长会话会有视觉不一致的问题。
Google 今天动作特别密集。Android Studio 推出 Bring Your Own Agent，支持 Claude Agent、Codex 等四十多个编码 Agent，官方说新终端工具让 Agent 完成 UI 任务快百分之七十七，token 消耗最多降到三分之一。另外，Google 还开放了 Gemini 和 Search 给更多应用，企业可以把服务接进 Google 的 AI 体验，这会直接影响消费者怎么发现和使用 App。广告这边，Alphabet 第三季度营收一千二百七十六亿美元，同比增长百分之二十五，但核心广告增速放缓，AI 搜索广告开始全球扩展，成了新的增长点。
OpenAI 这边，和 ServiceNow 扩大了合作，OpenAI 的模型和 Agent 进入 ServiceNow，ServiceNow 的工作流反过来接进 ChatGPT 和 Codex。企业工作流显然已经成了大模型落地的主战场。不过 OpenAI 也遇到点舆论麻烦，本周宣布了数学、计算机科学和物理领域的突破，但有研究者向 The Verge 表示，对它的发布方式越来越不满，可复现性的争议还在发酵。
再看安全和成本这两条线。安全创业公司 Cathedral 通过第三方软件，在漏洞赏金项目里用 AI Agent 入侵了 Anthropic 内部系统，触及销售、人力资源和 IT 数据，双方对入侵深度还有分歧，供应链再次被证明是 AI 实验室最大的软肋。另一边，Palisade Research 发现阿里 Qwen 3.8 的部分请求被路由到自家服务器，旧模型不受影响，推测是训练基础设施被学进了模型，本地部署的朋友建议做一下流量审计。成本治理方面，Anthropic 在计划 IPO 前推出了 AI 支出可视化工具，让企业看清钱花在哪。微软则首次以美元披露 Azure 单季收入，三百三十二亿美元，其中来自 OpenAI 相关的收入一百亿美元，整体季度营收九百二十三亿美元，同比增长百分之十九，连续十个季度创纪录。
开源和工具链也很热闹。Nvidia 开源了 Nemotron 3.5 Transcribe，转写、说话人识别、翻译一体，用文本 prompt 控制，活跃参数只有最强开源竞品的六分之一，还放出了八十万小时语音数据集。百度开源 Unlimited OCR 2，MIT 协议的三 B 模型，单次请求能解析上百页文档。MiniMax 开源了 MCode Stack，十七个技能文件和五份 checklist，覆盖代码审查、子 Agent 拆分和上下文预算，是它内部编码团队日常在用的配置。GitHub 上，obra/superpowers 单日涨了一千零九十五颗星，Nutlope/hallmark 单日涨了两千一百一十颗星，后者是给 Claude Code、Cursor、Codex 用的反 AI slop 设计技能。还有一个 openbot，是本地优先的桌面工作区，支持多 Agent 协同。
论文方面挑几个说。EmbeddingGemma 2 开源了统一的多模态 embedding，文本、图像、音频、视频一套表示，多模态检索可以直接换底座。h1 这篇讲自动定理证明的苦涩教训，简单 Agent 循环加扩展测试时算力，就能匹配人类设计的复杂工作流。还有一篇 Heads of Security，用少量可学习的注意力门做指令和数据分离，抵御提示注入，集成成本很低。
最后聊聊圈里的情绪。TechCrunch 一篇文章说 AI 专家已经脱离大众，科技领袖炫耀用 AI 和家人建立连接，恰恰暴露了和普通用户的脱节。Instagram 负责人 Adam Mosseri 也承认，围绕 AI 的负面情绪还会变得更糟。本地 AI 社区则在热议两件事，一是明年 GPU 价格可能大幅下跌，二是有人把三十二位 RISC-V CPU 直接构建进 Qwen3.5-4B 的权重里，让模型内部能执行指令，这对 tool calling 和 computer use 挺有想象空间。
今日观察。今天最清晰的信号是，前沿模型的竞争已经从跑分转向垂直场景加生态入口。Gemini 4 Carbon 把网络安全当首发卖点还限制访问，Google 同时把 Android Studio 和 Search 开放给第三方 Agent，OpenAI 把 ServiceNow 拉进 ChatGPT，入口之争已经打到 IDE 和办公流里。另一条暗线是信任，Anthropic 被 Agent 攻破、Qwen 被曝请求外泄、AI 高管被指脱离大众、Google 搜索回避敏感问题，这些叠在一起说明能力已经不是唯一瓶颈，可审计性和公众接受度正在成为规模化的硬约束。对开发者来说，今天最实用的动作，是去看看 MCode Stack 和 openbot 这类 Agent 工程化产物，方法论和工具链的沉淀速度，已经快过模型本身的迭代节奏了。好，今天就聊到这，我们明天见。
