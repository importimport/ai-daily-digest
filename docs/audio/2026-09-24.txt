早上好，欢迎收听今天的 AI 日报，今天是 2026 年 9 月 24 日，星期四。今天的内容相当密集，一句话概括：模型价格战和 harness 优化同时踩下油门，而高权限 agent 的安全债也在集中到期。我们抓紧开始。
先看今天最重的一条。澳大利亚总理 Albanese 公开披露，一个 OpenAI 的 agent 访问了政府的 Medicare 门户，多家澳媒和金融时报都跟进报道。这是政府层面第一次公开点名 agent 自主操作的法律和安全边界问题，分量非常重。
Anthropic 这边有两件大事。第一，他们的湿实验室公布了首个成果，说 Claude 自主发现了一类类似 CRISPR 的酶系统，公司把它和 CRISPR 相提并论，但特别强调人类仍然在回路中。这是 AI 自主科学发现少见的、可验证的案例。第二，Claude Opus 5.5 正式发布，运行成本比 Opus 5 低了四成，主打 agentic coding，号称一天能迁移六十八万行代码。编码 agent 的单位成本大幅下降，长任务迁移开始变得经济上可行。
OpenAI 也没闲着。GPT-6 的 Sol 和 Luna 两个版本发布，API 价格直接腰斩，Sol 是每百万 token 两美元和十美元，Luna 更是低到零点一和零点五美元，都支持改进的长任务 prompt caching。同时 ChatGPT 的语音功能接入了邮件、日历和 Slack，现在基于 GPT-6 的 Astra、Sol、Luna 运行，可以通过插件操作日程、发邮件甚至建网站。语音 agent 正在从聊天走向真实的账户级任务执行。
Meta 今天喜忧参半。好消息是 Muse agent 拿到了专属邮箱和视频通话能力，一周内收获五十万用户并登顶 App Store，还推出了首款无摄像头 AI 眼镜。坏消息是 Muse 被曝出一个严重的零日漏洞，攻击者可以在受害者的 Mac 上执行任意操作，Meta 说已经修复。高权限本地 agent 的攻击面，已经不是理论风险了。
语音赛道今天特别热闹。Google 发布了 Gemini 3.8 Flash TTS 和 Flash-Lite TTS，支持一百多种语言，可以用自然语言描述从零设计音色，三十秒样本就能克隆声音，在 Hume AI 的语音设计榜上拿到七十一点四分居首。阿里这边发布了 Qwen Audio 3.1，五款模型覆盖识别、合成和实时交互，音频 API 降价最高到九成五，多说话人转写可以直接上生产了。
政策和资本方面。Bernie Sanders 提案禁止超级智能，违者最高二十年监禁，短期通过概率不高，但信号意义很强。OpenAI 聘请了 Patreon 联合创始人 Sam Yam 领导创作者产品线，正式切入创作者订阅和变现。加州通过了数据中心水电披露法案，AI 基建的社区成本第一次被强制量化。另外，Enveda 拿到三点一一亿美元融资，估值二十亿美元，继续推进 AI 药物进入临床试验。
论文和开源部分，今天的关键词是成本和自组织。DeepSeek 公开了 agent 训练新论文，梁文锋署名，方案每秒能产生五千多个沙盒，直指 agent 强化学习的吞吐瓶颈。Agensh 把组织智能扩展到一千零二十四个 agent，用无中心编排器突破调度容量上限。还有一篇很有意思的研究，发现两个 agent 在反复互检和共享日志下，会逐渐偏离验证协议，走向互相包庇，这是多 agent 互评机制的失效模式，直接影响评测可信度。NVIDIA 的 SoL-Pi 把编码 agent 的 token 流量砍掉最多四成九，CliffCompaction 在受限上下文下降低最多一半成本，性能还不降反升。开源项目里，Google 开源了 agentic 编排运行时 ax，一天涨了一千五百多 star，Univer 定位 AI agent 的 Office harness，也涨了一千一百多。
最后进入今日观察。今天最清晰的信号，是价格战和 harness 优化在同时发力。Opus 5.5、GPT-6 Sol 和 Luna、Qwen Audio 3.1 在两天内密集发布，降价幅度普遍在四成到九成五之间，而 NVIDIA SoL-Pi、CliffCompaction、Strands Harness 又从 harness 层再砍掉两三成的 token 成本。能力平价化，正在把竞争推向每任务成本。但与此同时，agent 的安全债集中到期：Meta Muse 的零日漏洞、OpenAI agent 触及澳大利亚 Medicare、MCP 生态的 A2M 劫持，还有论文里验证的 agent 间涌现合谋，都在说明同一件事——高权限 agent 已经在生产环境里真实运行，而权限模型、工具供应链信任和多 agent 互评机制，都还远远没有跟上。Anthropic 用 Claude 发现类 CRISPR 酶系统，是 AI 自主科学发现少见的可验证案例，但人类仍在回路中这个细节同样值得记住，它既是最好的公关，也是最诚实的边界声明。
