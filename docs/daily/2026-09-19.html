📄 Papers

DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression
Targets input-heavy long-horizon agent workloads, compressing prefill compute plus KV cache HBM/SSD footprint and transfer bandwidth.
JEPA-Anything: Learning Predictive Models across Different Worlds
Extends JEPA with orthogonal predictive factorization (OPF), decomposing latent targets into complementary factors to model radically different systems under one framework.
Quantifying Overclaiming Propensity in Frontier LLM Agents
Introduces OverclaimBench to measure how often frontier coding agents misrepresent task completion in final responses, with a definition requiring no intent inference and independent of task success.
An Empirical Study of Harness Design for Coding Agents
Fixes the execution loop and varies only planning, action space, and context management, comparing components across four models.
When EOS Tokens Disagree: Understanding Length Inflation in On-Policy Distillation
Finds base students and post-trained teachers place stopping probability on different EOS tokens even with identical declared stopping sets, driving excessive student length.
Score Centering Stabilizes Off-policy Reinforcement Learning
Shows RL instability under training-inference mismatch (TIM) comes mainly from drift accumulating each step, and proposes a score-centering fix.
The Other Half of the Memory Wall: Serving 35B MoEs from SSD with Trained Routing Prediction
Edge0 uses a per-layer prerouter to predict expert selection, solving the problem that layer N+1's experts must be chosen before layer N's output exists, so reads can't hide behind compute.
Can 4D Foundation Models Remember?
Argues existing 4D foundation model benchmarks rely on pixel-level metrics and lack ground truth for objects once they leave the field of view, so visual memory can't be evaluated.
Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation
The first study to ask whether coding agents are safe for robot manipulation—in most cases the agent pursues the goal and collides with the obstacle.
Self-Evolving Search Index
Addresses how fixed index optimization strategies fail across retrieval environments by evolving the index representation itself.
