📄 Papers

Weight-Space Programming Doesn't Need Transformers
Frontier LLMs write target weights by hand without gradient training, showing Transformers aren't necessary and challenging the "architectures chosen for gradient descent" assumption.
Multi-Branch Transformer (MBT)
Runs multiple independently parameterized branches of sequential blocks in parallel between shared initial and final layers, a third scaling path beyond width and depth.
Termination Lag: Coding Agents Solve Early but Stop Late
Across 5 models, 2 frameworks and 3 SWE-bench datasets, 38–82% of successful runs are already correct at the first edit, yet agents keep burning substantial steps.
More Agents, More Samples, or More Thinking?
Across 516 multi-agent configurations, accuracy differences vs. single greedy passes are negative overall; prior gains were confounded by sample multiplicity and compute.
Correct Labels Are Not Enough: Reliable Metadata Can Silently Control Model Behavior
Metadata always marking the correct option (e.g. Reward: 5) makes 7–9B models pick a wrongly annotated option 97–100% of the time at test time.
MedJev: A System One Vision-Language Decision Model for Medical Images
Maps images, questions and candidate answers directly to a single multi-choice decision, avoiding autoregressive reasoning tokens and their latency and parsing errors.
SilentGuard: Invariant-Aware Harness Enforcement against Silent API Failures
Moves judgment from the model to the tool-calling harness, checking every result against invariants to fix the "model sees the problem and answers anyway" failure.
JEPA4R: Embodied JEPA World Models with 4D Point Planning
Observes single-depth-camera point clouds and predicts and plans in latent space, recovering metric geometry that 2D images leave implicit.
ResWAM: Learning What Changes, Not What Stays, for World-Action Models
Supervising complete future observations lets static background dominate the loss; the new method focuses on task-relevant robot and object motion.
RISA: Recoverable Sparse Attention for Block-Diffusion Language Models
Targets the memory-bound bottleneck of repeatedly reading a growing KV cache during long-context inference in block-wise diffusion LMs.
