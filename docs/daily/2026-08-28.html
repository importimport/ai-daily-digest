📄 Papers

PILOT in the Loop: Live self-improvement for long-horizon agents
Proposes a new paradigm where agents use emerging experience in real-time to redirect the active run and update the persistent harness, rather than processing after execution ends.
TTPO: Test-Time Policy Optimization
Introduces test-time training without ground-truth labels, using majority-vote pseudo-labels to enable TTT where RL and OPSD cannot.
Prefix Sliding for efficient test-time scaling
Finds most intermediate reasoning tokens lose importance as reasoning continues, proposing prefix sliding to reduce memory cost of long reasoning traces.
SWE Refactor Bench: Can coding agents complete whole-repository stack migration?
Existing benchmarks only evaluate behavioral correctness, not whether migration actually occurred, allowing agents to "cheat" by copying original implementations.
GameWAM: A World Action Model for video games
First exploration of World-Action Models under real video game dynamics and open-ended interaction, unifying world dynamics modeling with task policies.
CritICL: Inference-time weak-to-strong generalization from small LM failure modes
Leverages structured failure patterns across model scales within the same family for efficient inference-time enhancement without repeated generation or external verification.
SWE-Prime: Fewer trajectories, better performance
Shows successful trajectories still contain ineffective, redundant, or risky steps; using them directly for SFT introduces noisy supervision.
Understanding Evolution Strategies for LLM reasoning
Systematically studies ES optimization behavior for LLM reasoning post-training, theoretically and empirically showing ES achieves broader reasoning coverage than GRPO.
Google releases GlucoFM: 0.72M-parameter foundation model for continuous glucose monitoring
Dual-stream architecture splits CGM traces into slow physiological and transient event streams, beating 135M and 385M larger models with a fraction of parameters.
