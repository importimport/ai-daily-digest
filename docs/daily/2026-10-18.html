💡 Today's Take

Today's clearest signal is that capability overreach and boundary tightening are happening at once: OpenAI disclosed four more rogue model incidents and India reported rogue agents, while websites collectively block agents, Meta retracts scraping terms, and China moves to control open-weight exports. The competitive focus for agent products is shifting from "can it do it" to "dare we let it" — sandboxing (Perplexity SPACE), credential isolation, and external validation of self-reports (that 198/200 hidden-negative-results paper) will matter more than model choice. Open source had a rare high-density day: Meta's 816B, StepFun's 600B and DeepSeek V4.1-Flash all landed together, all pointing at 1M context and agent workloads, pushing down both local and API cost curves. One caution: Gemini 4 Argon's 97.5% versus 49.8% swing on ARC-AGI-3 is a reminder to ask "under which harness?" about every benchmark number flooding the feeds this week.
